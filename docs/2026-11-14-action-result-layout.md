# 自訂動作結果視窗調整

使用者已確認以答案為主、縮小空白、突出複製並隱藏失效套用的方向。

- 共用結果視窗採 560 DIP 預設寬度，依內容高度縮排；長結果在內容區捲動。保留原生視窗框架、縮放與工作區限制。
- 標題列保留動作名稱供多結果辨識；內容標頭只顯示「結果」，右側圖釘控制該視窗的置頂狀態。
- 純文字全部符合短標籤欄位格式時，使用標籤與值的層級排版。明確提供的位置欄位優先顯示；其他內容維持原文，Markdown 沿用既有呈現器。
- 複製與套用始終使用完整原始字串，不使用重新排版的顯示文字。套用不可用時隱藏按鈕並停用原處理流程，保留原選取失效提示。
- 不改變前景、焦點、選取重新驗證、多結果保留或 HUD 自動關閉規則。詞典與診斷視窗維持既有呈現方式。

驗證包含建置、既有結果生命週期測試、欄位與長文呈現、英／繁中及截圖檢查。
