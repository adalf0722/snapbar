# 自訂動作結果保留

本次範圍依使用者確認：先讓結果像便利貼一樣保留，地圖啟動另案處理。GeoIP 匯出腳本、1.5 秒等待、BrowserLauncher 與 Job Object 均不修改。

## 行為

- 從選取文字執行自訂動作，視窗／Markdown 結果與錯誤詳細資訊各開獨立視窗，不覆蓋既有結果。按 X／關閉或結束 SnapBar 才移除；新視窗稍微錯開並限制在工作區。
- 視窗不搶焦點，保留工作列入口。預設置頂，可個別取消置頂；取消置頂不關閉結果。
- 已授權且進入腳本執行階段的視窗／Markdown 查詢，可跨來源焦點變更完成與顯示。來源失效只移除原文操作權限。
- 明確取消、設定變更、新 capture 取代執行，以及程式停止仍會取消未完成查詢。腳本回報 cancelled 時不建立結果。逾時與失敗保留原有診斷。
- 初始選取驗證、密碼欄拒絕、相容模式偏好、剪貼簿租期與取消／逾時清理不變。自動剪貼簿輸出與直接替換原文仍須來源有效。套用每次重新驗證來源；舊結果不得因新結果出現而重新取得寫回權限。

## 實作範圍

`ActionResultWindows` 管理選取控制器的自訂結果，與詞典彈窗分開。所有已開視窗參與指標命中測試、來源失效與結束清理，關閉後從集合移除。短暫 HUD 保留自動關閉；詞典、OCR 本機動作與 AI 面板的互動規則不在此次修改範圍。

執行中的唯讀查詢以 invocation 的 cancellation token 與控制器生命週期判斷是否可呈現；原文操作仍使用原本的 selection identity、generation、前景與 Probe 驗證。即使前景未變，重新查詢或來源驗證失敗也不延長舊結果的套用權限。

## 驗證範圍

新增桌面 `PersistentResults` 套件，涵蓋多視窗保留、關閉互不影響、個別置頂、真實 Runner 跨前景計時器完成、取消仍抑制結果、自動剪貼簿仍受焦點限制、舊 Apply 不得寫入、結束清理等案例。相容模式測試同步改為驗證唯讀結果可保留且不可套用。完整結果另記於 `docs/p0-validation.md`，未通過前不宣稱完成。

結果仍只保留於目前執行階段，不新增磁碟保存或重啟還原功能；測試只使用可丟棄 fixture，不記錄選取文字或剪貼簿內容。
