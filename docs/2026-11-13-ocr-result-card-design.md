# 擷取文字介面調整

使用者已同意保留現有功能，重整結果卡與動作面板。目標是讓辨識文字成為主角，讓複製、編輯及接續動作一眼可懂。

- 結果卡預設寬 480、高 360 DIP，文字 16 DIP；保留縮放、捲動與視窗調整大小。複製使用實心強調色，動作使用次要按鈕，重新框選使用低干擾按鈕。
- 動作選單以按鈕為定位基準，提供結果卡下、右、左、上四種候選位置，由 WPF 依工作區可見範圍選擇。選單上限為 300 × 360 DIP，搜尋、處理範圍與管理入口固定，動作清單獨立捲動。
- 最近動作最多呈現三筆，其餘保留於其他動作；搜尋涵蓋全部可見動作。保留停用原因、明確鍵盤焦點、雙語、選取範圍、動作票證與過期結果驗證。

驗證包含 Release 建置與 Core runner、OCR 動作桌面測試、繁中及英文畫面檢視、受限工作區與長清單，以及選取變更與過期結果拒絕。真實跨螢幕及各 DPI 組合需分別記錄，不能以定位候選測試代替。
