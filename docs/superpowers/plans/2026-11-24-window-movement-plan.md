# 多螢幕自由移動實作計畫

依據已核准的 [設計](../specs/2026-11-24-window-movement-design.md)。目前環境缺少 writing-plans 技能；經使用者同意繼續，以此計畫記錄步驟。

1. 在 Core 新增標題列可操作性與最小救援位移政策，以注入工作區清單測試，不依賴實體多螢幕。
2. 在 Windows 層取得實際工作區與標題列可拖曳範圍；讀取失敗不猜測螢幕邊界。
3. 拆開共用視窗輔助程式的一般移動、初次尺寸、必要救援及明確 override；拖曳期間延後處理配置事件。
4. 增加單螢幕 WPF 回歸測試，驗證原生移動、縮放、放開後位置、DPI 訊息、重新顯示救援及 override。
5. 新增雙語更新說明，執行建置、Core 與相關桌面測試，記錄結果與未涵蓋的真機多螢幕條件。
