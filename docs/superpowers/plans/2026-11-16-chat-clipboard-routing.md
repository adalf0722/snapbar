# 聊天相容讀取實作計畫

1. 取得企業微信原生焦點／視窗類別和 MSAA 角色／保護狀態，確認適配邊界。
2. 實作與 token 綁定的企業微信來源驗證；保留通用來源資格。
3. 已驗證備援候選提前結束原生重試，加入僅自動相容讀取適用的失敗退避。
4. 加入有意義的安全與路由測試、雙語更新說明，執行建置和相關 runner。
5. 關閉會干擾的選字工具，以可丟棄文字及既有訊息做實機對照，不送出訊息。
6. 記錄成功率、耗時與限制，交付經驗證的開發版與驗證紀錄。
