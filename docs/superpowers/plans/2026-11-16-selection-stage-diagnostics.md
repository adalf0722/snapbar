# 選字診斷實作計畫

1. 擴充可選 Probe 診斷協定，限制為數值、布林與固定階段。
2. Probe 重設每次請求的診斷，追蹤候選及回退驗證。
3. App 透過環境變數開關輸出有界 JSONL，禁止序列化 Selection。
4. 補協定測試及雙語更新說明，執行建置、Core 和 Probe smoke。
5. 正常結束舊版，啟動診斷版重現微信，依階段更新調查紀錄。
6. 關閉診斷版，恢復使用者原版本，交付證據與修正建議。
