# SnapBar Windows P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.
>
> 本次採目前對話內依序執行。環境已找到 writing-plans，但未找到 executing-plans；以下以明確任務、驗證與檢查點記錄執行，不宣稱使用不存在的技能。目錄尚未建立 Git repository，不建立工作樹或自動提交。

**Goal:** 交付可執行的 Windows 選字原型，驗證 UIA 讀取、不搶焦點動作列、保守的 Cut／Paste 與剪貼簿不受讀取影響。

**Architecture:** 將 UIA 放在可終止並重啟的背景 helper process，避免第三方 provider 卡住 WPF。主程式以 generation ID 丟棄過期結果；寫回必須重新驗證視窗、程序及原始文字範圍。P0 預設只用 UIA，剪貼簿 fallback 維持關閉，無法讀取即回報不支援。

**Tech Stack:** C#、.NET 10、WPF、UI Automation、Win32、無第三方測試套件的 console 驗證器。

## 範圍與實作檔案

本工作包不包含 P1 全部功能。交付 Copy／Cut／Paste 原型、手動快捷鍵、可開關的滑鼠監聽、診斷狀態、獨立測試視窗與執行說明；搜尋、路徑、完整設定、AI 與腳本依原分期進行。

## Task 3：UIA helper

- [x] 建立每行 JSON 的 Capture／Validate 協定；stdout 只作內部通訊，不寫入一般 log。
- [x] 在 MTA 主執行緒讀取 focused element／游標元素及有限祖先；密碼控制項直接拒絕，不讀整份文件。
- [x] 保存單一工作階段的 cloned ranges；重新驗證 runtime ID、PID、程序啟動時間、文字與 range endpoints。
- [x] 輸入長度最多 32,768 個 UTF-16 code units、最多 16 段；超限回報不支援，不截斷後假裝完整。
- [x] helper 非同步管線讀取超過 1.5 秒即終止並下次重啟；不可讓失敗請求無限堆積。主程式退出時清理 helper。

## Task 4：事件與非啟動動作列

- [x] 註冊 Ctrl+Alt+V；衝突顯示錯誤。初次啟動自動監聽保持關閉，使用者按下啟用後才監聽滑鼠手勢。
- [x] hook 只發布事件，所有 UIA 都不在 hook 內執行。拖曳／雙擊／三擊完成後合併 120ms；普通單擊只關閉。
- [x] 使用 `WS_EX_NOACTIVATE`／`WM_MOUSEACTIVATE` 保留原前景；滑鼠可點擊動作按鈕。
- [x] 外部點擊、按鍵、捲動與前景變動使快照失效；自己的 SendInput 事件不重入。
- [x] 使用實體像素定位 HWND，適配 PerMonitorV2；Pure Core 計算工作區限制。

## Task 5：Copy／Cut／Paste

- [x] Copy 只寫入本次有效快照文字，不模擬 Ctrl+C。
- [x] Cut／Paste 只對單段、已確認可編輯且仍在前景的原始控制項執行。
- [x] 發出 Ctrl+X／Ctrl+V 前重讀範圍；如果使用者仍按住修飾鍵則拒絕，避免干擾鍵盤狀態。
- [x] Paste 使用現有剪貼簿，讀取流程不暫借剪貼簿。SendInput 回傳只標為「已送出」，不誤稱目標已處理。
- [x] 密碼欄位、沒有選字、視窗改變、範圍改變、UIA 逾時均提供明確狀態且不寫入。
