# AI Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the approved WPF AI panel with real configurable HTTP services and selection-safe replacement.

**Architecture:** Core owns bounded prompt settings and in-memory rewrite state. Windows owns bounded HTTP adapters and DPAPI keys. App owns the WPF panel, settings/dialogs and the controller's original-selection handoff.

**Tech Stack:** .NET 10, WPF, HttpClient, System.Text.Json, Win32 DPAPI, existing console test runners.

## Global constraints

- Preserve password rejection, source/focus/candidate identity, generation cancellation, clipboard sequence checks and existing preferences.
- Never log or persist selected text, free instructions, API response text or credentials. Version history remains in panel memory.
- Only explicit command execution sends text. Never execute model output or load remote Markdown resources.
- Respect existing uncommitted action-delete/undo changes; stage only task-owned files when committing.
