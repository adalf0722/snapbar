# Auto-copy Implementation Plan

> Execute in this chat, using the approved auto-copy design and existing checkout. Preserve selection safety and existing compatibility preferences.

**Goal:** Optional mouse-selection copying with Ctrl gating and optional unobtrusive success feedback.

**Architecture:** Core owns normalized preferences and gesture policy. Windows records modifier state and provides a clipboard writer that checks sequence under the clipboard lock. App shares capture between toolbar and copying, validates before writing, and owns settings and feedback.

**Tech Stack:** .NET 10, WPF, Win32, existing console test runners.

- [x] Extend `InputEvent` with a modifier snapshot on mouse selection. - [x] Add `SelectionController.AutoCopy.cs`. Execute `pwsh -NoProfile -File scripts/check.ps1`, then relevant isolated desktop suites serially. Record completed checks and manual cross-app/DPI limitations in `docs/p0-validation.md`.

## Verification criteria

Defaults and upgrades never enable copying. Ctrl reverses the intent of the two modes; any other modifier rejects automatic copying. Background, password, excluded, stale and externally changed clipboard cases never write. Toolbar-only, copy-only, both and neither preserve their independent behavior. Success feedback follows a completed write only. New selection and settings changes cancel pending work. No selection or clipboard contents are logged.
