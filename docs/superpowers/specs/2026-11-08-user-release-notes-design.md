# 面向使用者的自動發布說明

使用者已同意將發布頁改成先說明更新價值與開始使用方法，再提供下載、必要限制及折疊的技術資訊。這次實作處理 main 自動預覽版，保留既有桌面證據、套件驗證、版本選擇及失敗重跑保護。

直接依賴 GitHub 產生的 PR 清單會缺少使用情境；從 commit 標題自動改寫也無法可靠推斷使用者利益。採用隨功能提交的繁中 JSON 說明，包含標題、摘要、一到三項重點及使用方式，由開發者確認內容符合實作。

以完整 Git 歷史比較前一公開版本及確切來源 commit，只彙整新增說明；首次發布讀取全部說明。桌面或套件變更沒有新說明時阻擋發布，歷史或格式錯誤亦阻擋。純網站、文件、測試及工具更新明確顯示沒有桌面功能更新，不虛構效益；目前不改變每次 main push 發布預覽版的頻率。

驗證涵蓋版本範圍、中文保留、舊說明排除、工作目錄隔離、缺漏與佔位內容拒絕、無桌面更新的文字，以及實際 publisher 的無寫入失敗、下載連結、版面順序與既有重跑保護。人工正式 Release 的文字仍由發布者管理。
