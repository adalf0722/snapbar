# OCR 更多選單呈現設計

日期：2026-11-09。依使用者實際截圖審閱，使用者已同意改善搜尋列、文字作用範圍提示及動作分組，並同意馬斯克視角補充的高度上限、同列簡短原因與「其他動作」標題，以「同意 go」授權實作。

## 目標與範圍

讓使用者打開更多時，立即知道可以搜尋什麼、動作會使用哪些文字，以及如何找到常用動作。

採用完整改善 OCR 選單的方案：共用既有字型、圖示、色彩及最近使用資料，補齊搜尋、來源提示與分組。只加 placeholder 的最小方案無法解決來源與層次問題；全面改寫原生選字工具列與選單則擴大了本次範圍。此次不修改原生 `PopupWindow` 的輸入監控或選取生命週期。

維持結果卡的「複製文字／重新框選／更多」、既有共用動作清單、設定保存、取消、輸出分派及套用驗證。不新增動作、釘選設定、另一份最近使用清單或 OCR 專屬偏好。

## 搜尋與來源提示

- 搜尋列顯示放大鏡與「搜尋動作…」placeholder；英文為「Search actions…」。placeholder 只在輸入為空時可見，不作為實際 query，也不攔截點擊。
- 搜尋列是輸入介面，不是可執行選單項目。移除外層整列藍色反白；輸入框保留清楚的細焦點框，搜尋圖示和內距與動作列對齊。不要用停用父容器或關閉 hit-test 的方式妨礙輸入。
- 開啟時聚焦搜尋框，保留 OCR 編輯框的反白範圍。篩選仍支援顯示語言名稱、原有名稱、ID 與既有別名，不觸發動作執行。
- 搜尋列下顯示低干擾的「文字來源：全部辨識文字」；有反白時改為「文字來源：所選文字」。不在此處重複顯示實際 OCR 內容，也不新增字數計算或截斷預覽。
- 來源提示依目前編輯框選取更新；真正執行時仍依既有票據取當下校正後的全文或反白。`UseSelection=false` 的動作繼續不使用文字，不能因新增來源提示而變更其輸入語意。

## 清單分組與空狀態

- 沒有搜尋時，依共用 `ActionSettings.RecentIds` 顯示「最近使用」，沿用現有最多五筆的規則；只有可見且屬於 OCR 清單的項目才列入。
- 其餘動作顯示於「其他動作」，沿用既有目錄順序。每個動作只出現一次；隱藏項目完全不顯示，複製、剪下、貼上仍維持目前 OCR 選單的排除規則。
- 最近使用群組沒有項目時不顯示空標題。所有動作皆在最近使用時，也不保留空的其他群組。
- 搜尋中改為單一「搜尋結果」清單，不重複最近使用項目。沒有匹配結果時顯示「找不到符合的動作」，清單區保留適量空間；此時 Enter 不執行任何動作，也不開啟管理頁。
- 「管理動作」是固定底部入口，與清單以細分隔線區分；搜尋不隱藏此入口。使用者明確聚焦或點擊它時才進入既有設定，編輯內容與選取範圍保持不變。

## 視覺規則

- 以目前 OCR 結果卡的淺色表面及 `ActionUi` 色彩、字型、邊線與圖示為基礎，不引入新的主題設定。選單外框、搜尋框、群組標題與 footer 採一致內距。
- 選單目標寬度 320 DIP，依目標螢幕工作區縮小，不以硬編碼固定寬度造成超出螢幕。外層內距約 8 DIP；圖示 16 DIP，圖示與標籤間距約 8 DIP。
- 單行動作列至少 36 DIP 高，使用 13 DIP 左右的文字；群組與來源提示使用 12 DIP 淡色文字。hover／鍵盤選取只高亮可執行動作列，標題與搜尋容器不套用動作選取底色。
- 不適用動作保留灰色名稱，盡量在同一列顯示簡短原因，例如「需單字」或「需有效網址」，放不下才換行。完整說明保留在 tooltip 與輔助資訊。沿用現有適用性政策與本地化原因，不增加新的可執行判定。
- 停用原因與動作文字皆可換行，列高隨內容增長，不使用省略號藏掉唯一的原因。保留停用 tooltip 與輔助說明；不能只靠灰色表達狀態。
- 一般情況選單總高度上限約 420 DIP，小工作區依目標螢幕可用高度與 DPI 再縮小，不以填滿高度為目標。清單過長時只捲動清單區，搜尋與底部管理入口保持可達；靠近螢幕邊緣時仍可完整操作。

## 鍵盤、生命週期與可及性

保留 Down 由搜尋框進入第一個可用動作、方向鍵移動、Enter 執行，以及 Esc 先關閉選單返回編輯框、再按 Esc 才關閉結果卡的規則。群組、來源提示、停用動作與空狀態不成為可執行項目。鍵盤焦點移動時讓該列進入可見區，Tab 不落入沒有操作意義的容器。

保留 `OcrMore`、`OcrActionSearch`、`OcrAction_<id>` 與 `OcrManageActions` AutomationId；新增穩定來源提示、群組與空狀態識別。搜尋框有可讀取名稱，placeholder 不替代輔助名稱。沿用視窗開啟時語言快照、使用者自訂名稱及圖示。

每次開啟仍讀取最新設定，點擊執行前仍驗證動作定義、來源卡、文字版本、選取範圍與工作身分。只調整呈現，不改寫或放寬現有 `LocalActionTicket`、`ActionOutputRouter` 與原生來源的權限規則。關閉／重選／退出必須清理新增選單事件與視覺參照，不留下重複事件或舊設定清單。

## 驗收與交付

1. 繁中／英文均顯示正確 placeholder、來源提示、群組、空狀態與管理入口；使用者自訂動作名稱與辨識文字保持原文。
2. 實際開啟搜尋列，驗證空字串與輸入後的 placeholder 狀態，搜尋容器沒有整列藍色動作反白，輸入框仍可聚焦輸入。
3. 反白／全文提示切換正確，開關選單、輸入 query 及鍵盤導覽不清除原選取；執行仍傳入正確的校正後文字。
4. 最近使用分組與共用設定一致、動作不重複、隱藏項目不出現、空群組不殘留；搜尋無結果時按 Enter 不開啟管理頁。
5. 停用原因直接可見且有輔助名稱；縮小工作區、長標籤與多動作清單仍可捲動到最後一項並操作管理入口。
6. 保存中英文的空搜尋、搜尋有／無結果、最近使用分組、停用原因及受限版面視覺證據。除分開渲染卡片／選單外，也核對一次實際展開的相對位置；桌面擷取使用拋棄式背景與測試文字，避免保留使用者其他視窗。
7. 執行 repository checks、OCR 共用動作、語言及外觀相關套件，依實際改動選取鍵盤回歸。不得刪除或放寬既有票據、取消、剪貼簿、Undo 與原生安全斷言；原生捲動既有基準失敗另行保留，不將其誤寫成本次通過。
8. 實作完成新增唯一命名的繁中更新說明，將真實測試、截圖路徑與未具備的 DPI／多螢幕驗證限制寫入 `docs/p0-validation.md`。文件使用 UTF-8 無 BOM 並嚴格解碼驗證；本次不包含安裝、替換套件、推送或公開發布。

## 規格自查

已核對：搜尋提示不進入 query、容器不偽裝成動作選取、來源提示不改變無輸入動作語意、群組不重複項目、鍵盤忽略非動作列、管理入口不被 Enter 誤觸，並保留共用動作設定與全部來源安全契約。具體數值為實作初值，需以真實展開畫面與受限版面調整，不宣稱已完成視覺驗收。
