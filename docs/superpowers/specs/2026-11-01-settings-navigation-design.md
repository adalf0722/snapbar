# SnapBar 設定導覽與對外介面設計

日期：2026-11-01。

狀態：使用者已選擇 A「左側固定導覽」。本文件將已選版型整理為實作規格，待文件審閱後進入實作計畫。

## 目標與現況

目前 `MainWindow` 將全部設定放在單一 `StackPanel` 與整頁 `ScrollViewer`，預設視窗就會出現垂直捲軸。動作管理及 AI 服務另開視窗，AI 命令新增、編輯、刪除只存在 AI 執行面板。設定分類與管理入口尚未形成完整體驗。

採用 A 草圖的左側導覽與右側內容區。一般設定在預設尺寸內完整可見，AI 命令可直接從設定管理，不需要先選取文字或建立執行工作階段。整合既有功能並統一視覺，不新增網站、帳號、付費、同步或真實 AI 測試請求。

參考草圖位於本機 `.superpowers/brainstorm/settings-20261101/content/settings-layout.html`。該目錄被 Git 忽略，正式需求以本文件為準；瀏覽器草圖的 S 字母標誌、模擬資料及未接通的按鈕不直接成為正式產品資產或功能。

## 導覽與頁面

左側導覽固定顯示六個分類，單層結構，圖示搭配文字。右側固定頁首、內容區與頁尾。切換分類不保存任何使用者偏好，也不重新載入或重設草稿。預設開啟「一般」，同一次程序內重新開啟設定保留目前分類。

| 分類 | 內容與主要操作 |
| --- | --- |
| 一般 | 自動偵測開關、既有 Ctrl+Alt+V 快捷鍵說明、動作列示意與前往動作列設定入口、關閉後背景待命說明 |
| 動作列 | 既有動作預覽、外觀、動作列／更多／隱藏分組、排序、新增、編輯、匯入、刪除及復原；搜尋引擎設定作為同頁的次級「搜尋」子頁 |
| AI 命令 | 命令搜尋、分類篩選、命令清單、釘選、新增、編輯、刪除；可直接開啟既有圖示選擇器 |
| AI 服務 | 既有服務選擇、完整 API 網址、模型 ID、API Key、既存金鑰狀態與移除金鑰選項；明確儲存服務設定 |
| 相容性 | 選字相容模式、Sublime 支援、排除 App 清單與加入／移除操作 |
| 關於與支援 | 真實版本資訊、背景待命說明、結束 SnapBar；進階區保留診斷事件與測試視窗入口 |

動作列頁的「動作／搜尋」次級導覽保持可見；既有動作位置分組在「動作」子頁內運作。搜尋保留 Google、Bing、自訂選擇，以及明確儲存和恢復預設；切換子頁不得丟失未保存的自訂網址。

關於與支援頁不放置尚不存在的說明、回饋或更新連結。現有可用功能先形成完整頁面，日後有真實支援網址才新增連結。

## 尺寸、捲動與視覺

- 初始目標尺寸為 980 × 720 WPF DIP，最小目標為 860 × 600 DIP。開啟時依目前螢幕的工作區限制尺寸與位置，不能讓視窗或操作按鈕超出工作區；不得以固定像素假設取代 WPF DPI 換算。
- 導覽欄約 180 DIP；頁首與頁尾使用自動高度，中間內容使用剩餘空間。頁面外距以 24–32 DIP 為主，資料列間距與控件高度遵循現有樣式。
- 設定視窗根節點不使用整頁垂直 `ScrollViewer`。一般頁在初始及最小支援尺寸內不得出現垂直捲軸，也不得裁掉內容。
- 命令、動作、排除 App 與診斷事件數量可增加，只允許各自有界的清單區捲動。導覽、主要操作、通知與頁尾保持可見。
- 較小工作區或文字放大造成密集表單超出可用空間時，允許內容區局部捲動。不得直接隱藏捲軸而使內容無法到達，也不得把所有文字或控件整體縮小。
- 服務與命令編輯的多行輸入可局部捲動；現有彈出編輯器仍需完整可操作。
- 保留現有淺灰背景、白色內容面、低對比邊線與單一藍色重點色。減少重複卡片和大標題；頁面標題約 22–24 DIP、主要文字 13–14 DIP、輔助文字至少 12 DIP。
- 使用既有 Fluent 圖示與產品品牌資產，圖示尺寸及筆畫一致。一般頁預覽反映使用者的實際動作排列、主題與標籤偏好，並說明正式顯示依選取情境決定；預覽不執行動作。
- 自動偵測狀態使用文字加圖示表達，不能只靠顏色。保留快捷鍵衝突、初始化失敗和設定保存失敗的明確提示。

## AI 命令管理

清單使用目前 `AiSettings.Prompts`，不建立第二份命令資料或新 schema。每列顯示現有圖示、名稱、分類及釘選狀態，提供明確的編輯入口與可存取的次要選單。

搜尋比對名稱、指示與關鍵字；搜尋與分類篩選同時生效。分類來自現有命令，包含「全部分類」與未分類項目，不能只支援草圖中的三個固定分類。空集合、無搜尋結果與達到既有 128 筆上限時都顯示對應狀態。保留全部既有名稱、指示、分類、關鍵字及圖示上限。

新增與編輯重用 `AiPromptEditorWindow` 的驗證、圖示預覽、進階選項與圖示選擇器。編輯維持原命令 ID；取消不保存。釘選更新 `PinnedIds`；刪除透過既有正規化移除失效的釘選與最近使用參照，不修改其他命令。

設定管理與 AI 面板共用 `AiPreferences`。保存成功後兩處即時刷新；仍在編輯的命令草稿不因其他命令變動而被覆寫，提交時以最新集合套用當前命令變更。保存失敗保留草稿並顯示錯誤，不顯示成功或清空編輯內容。

AI 面板保留既有快速新增、編輯與釘選能力，並提供前往設定中 AI 命令分類的入口。設定頁不提供「執行命令」按鈕，不建立無來源選取的寫回路徑。

## 元件與資料流

`MainWindow` 維持程序生命週期、系統匣、控制器及設定保存的協調角色，負責目前分類與全域狀態，不繼續累積六頁的完整建構程式。

將各頁整理成職責明確的 WPF 內容元件。動作管理與 AI 服務的既有視窗改為共享內容的宿主，以便設定頁嵌入；既有呼叫端與桌面測試需要獨立視窗時仍能使用同一份內容，不複製保存邏輯。

動作設定仍走既有正規化、保存回呼與 `SelectionController.ConfigureActions`。AI 設定仍透過 `AiPreferences.TrySave`、`Changed` 與 `AiSecretStore`；已保存服務與金鑰的保留、清除及錯誤語意不變。

從控制器或其他視窗要求「管理動作」時，顯示並啟用設定視窗，切至動作列頁；要求管理 AI 命令或服務時切到對應頁。不得同時建立不同步的兩個管理實例。設定切頁不終止執行中的 AI 請求，也不改變既有來源失效與取消規則。

設定頁離開或視窗關閉時不自行保存未提交的服務、搜尋或命令草稿。同一程序內切頁保留表單草稿；既有自動偵測、相容性、排序和釘選仍在明確操作後依原契約立即保存。服務設定成功後留在該頁並顯示已保存，獨立宿主可延續原本保存後關閉的行為。

各頁的驗證錯誤顯示在對應欄位或固定操作區；全域初始化、熱鍵及設定保存錯誤顯示在固定通知區。重要錯誤不得因切換分類而消失或被成功訊息掩蓋。頁尾避免宣稱所有內容皆已自動保存。

## 安全、相容與可存取性

保留密碼欄位拒絕、前景／焦點／候選身分驗證、過期結果取消、剪貼簿讀寫限制及原文替換權限。設定重整不得更改 Core、Windows 或 Probe 的動作許可政策。

一般剪貼簿相容模式遵循既有預設及保存偏好；Sublime 初次設定沿用明確啟用流程。保留暫借剪貼簿及可能出現在剪貼簿歷程的說明，不以視覺精簡移除實際副作用資訊。

API Key 不顯示為明文、不寫入一般設定或日誌；保留現有服務及網址分開保護的規則。診斷與新增 UI 日誌不得包含選取文字、命令輸入、AI 回應或剪貼簿內容。

導覽與清單提供文字標籤、焦點樣式及穩定的 Automation ID。Tab 可遍歷全部操作；導覽支援方向鍵與 Enter／Space 切頁。切頁後焦點留在可預期的導覽項或目標頁，不遺留於已隱藏的控件。命令篩選與刷新後保留可用焦點；IME 組字不得被導覽快捷鍵中斷。

## 驗證與完成條件

1. 檢查六個分類與外部管理入口，確認設定視窗可重開、系統匣與結束操作維持原行為，切頁不重置保存值或未提交草稿。
2. 在 100%、125%、150% 顯示縮放、初始尺寸、最小支援尺寸及受限工作區檢視實際 WPF 截圖。一般頁無整頁捲軸；每頁標題、主要操作與錯誤提示可達，長清單僅局部捲動。
3. 桌面案例驗證無選取即可管理 AI 命令、新增／編輯／取消／刪除／釘選、搜尋加分類、圖示、命令上限、失敗草稿保留，以及管理頁與既有 AI 面板同步。
4. 回歸動作分組、預覽、排序、匯入、刪除與復原；驗證搜尋引擎、自訂網址草稿、服務金鑰保留／移除、排除 App 與相容性偏好。
5. 執行 `scripts/check.ps1`，依改動更新並執行 Appearance、Lifecycle、Actions、Exclusions、AiPanel 及對應命令編輯／圖示桌面案例。發佈前必須取得目前原始碼的 Release 桌面證據，並依既有發布腳本建置與 smoke 驗證。
6. 將實際 UI 截圖、DPI 驗證、成功測試與仍未涵蓋項目記錄至 `docs/p0-validation.md`。瀏覽器草圖驗證不能代替 WPF 或桌面 Release 證據。

本次範圍完成後，使用者從設定即可找到並管理所有既有功能；一般設定不再依靠整頁捲動，AI 命令有固定入口，既有資料、安全限制與背景待命行為保持一致。
