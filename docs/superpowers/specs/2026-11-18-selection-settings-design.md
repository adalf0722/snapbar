# 選取與複製設定頁

使用者已同意將選取與複製從一般頁獨立，延遲控制改為局部展開，讓主要設定在標準視窗下容易看完。

## 頁面與互動

- 側欄在一般之後新增「選取與複製」，沿用鍵盤導覽、即時語言切換與固定頁面標題。
- 一般保留語言、登入啟動及 OCR 語言優先順序。
- 選取與複製使用兩張卡片：自動顯示動作列、自動複製。
- 延遲預設收合並顯示已儲存數值；展開後保留既有滑桿、精確輸入、還原及錯誤處理。
- 關閉動作列自動顯示時取消尚未儲存的延遲編輯，收合控制並保留數值。
- 關閉自動複製時隱藏觸發方式、使用說明與進階設定，重新開啟保留模式及提示偏好。覆寫剪貼簿提醒維持可見。
- 使用說明名稱明確指向自動複製；進階提示設定依需要展開。
- 預設內容在 980 × 720 視窗完整顯示，小視窗或展開時允許垂直捲動，不使用巢狀捲動區。

## 實作與驗證

將選取相關 UI 及其編輯生命週期移到 SelectionSettingsPage，不修改設定檔結構、選取判斷或剪貼簿執行邏輯。沿用雙語資源、儲存失敗回復及自動化識別碼。

執行建置、Core 測試與相關桌面套件；驗證一般與選取頁分離、延遲收合與數值同步、跨頁取消編輯、自動複製偏好保存、雙語標準及小視窗版面，產生截圖供視覺檢查。
