# SnapBar UI 精修設計

日期：2026-10-31。使用者已同意「安靜的 Windows 工具」方向，並授權繼續實作。

## 範圍

統一工具列、設定、動作管理與編輯器的色彩、字體、控制項及資訊層次。使用 WPF 現有架構，共用樣式，不改選取、安全驗證及動作執行契約。不實作 AI 功能；結果面板的視覺規則可供後續 AI 面板沿用。

## 視覺

背景 #F6F7F9，面板白色，正文 #20242C，輔助文字 #626B78，主色 #3867D6。中文優先 Microsoft JhengHei UI，正文 14 DIP、輔助文字至少 12 DIP、標題 24 DIP。控制項最小高度 36、圓角 8、面板圓角 12。控制項保留鍵盤、焦點、hover、按下、停用及唯讀狀態。深淺工具列皆有完整可讀的更多面板。

## 畫面

- 設定：SnapBar 標題、運作狀態、自動偵測開關與快捷鍵；動作列、搜尋、相容性與排除 App 各自分區；紀錄與測試視窗收進診斷。Sublime 仍需明確勾選，每次啟動不自動啟用。
- 我的動作：簡短頁首；新增為主要操作，匯入與復原為次要選單。預覽置於淡色面板中央，呈現實際工具列高度與圓角，不延伸成整條色帶。顯示三個位置群組及數量，保留上下排序、拖曳及顯示位置選擇，讓 hover／鍵盤焦點凸顯列操作。
- 編輯：保留左右分欄；左為動作設定，名稱／圖示同列，擴大腳本區；右為範例輸入與執行結果。網址按鈕為「預覽網址」，腳本為「執行測試」，只在執行中提供「停止測試」。儲存固定於頁尾，不因表單捲動消失。保留完整診斷及明確執行提示。
- 工具列：緊湊單排，統一圓角、邊框及互動狀態；更多面板跟隨深淺主題。沿用既有情境篩選、螢幕邊界與焦點規則。

## 驗證

執行 Release 建置與既有 Core runner；Windows runner 執行 action-layout、menu-keyboard、custom-actions、action-diagnostics、tray-lifecycle。檢視真實 WPF 視窗、下拉選單、深淺工具列及小視窗捲動。更新 p0 驗證紀錄，截圖輸出至 artifacts/ui-polish；實體混合 DPI 僅在有對應螢幕時宣稱驗證。
