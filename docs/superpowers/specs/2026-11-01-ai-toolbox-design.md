# AI Panel Toolbox Design

The user approved the two-area toolbox variant after comparing it with a shaded command rail. Both the command area and reader have white surfaces, matching thin borders, corner radii and internal padding, separated by a modest gutter. The window and original/result workflow remain the same.

The left area is labelled AI commands and keeps the combined search/instruction field, category filter, count and prompt management. Commands appear as a continuous two-column grid of compact neutral buttons. Search and the existing pinned/recent ordering remain authoritative; group headings are removed so they do not interrupt the spatial grid. Icons, wrapped names and a small pinned indicator distinguish commands. Pin and options controls appear on hover or keyboard focus without obstructing the main action. Long names wrap within a fixed two-line label and retain a full-name tooltip/accessibility name. The five defaults fit the normal window with the filter collapsed; larger collections scroll.

Keyboard behavior follows the visible grid, without wrapping at row edges: Down from the end of the input enters the first enabled command; Up/Down move by two commands, Left/Right move within the current row, and a missing cell in the last row clamps downward movement to its last item. Up from the top row returns to input. Enter executes, Esc from any command or its management controls returns to input without clearing the draft. Tab still reaches pin/options; existing input Esc behavior and Ctrl+Enter replacement stay intact. Focused commands scroll into view. Re-rendering after management preserves the command identity and focus where possible.

Scope is limited to WPF presentation and command navigation. No changes to HTTP, credentials, persistence format, selection safety, clipboard or result/version behavior. Tests cover grid placement, boundary navigation, filtered/single/empty collections, long names and many-command scrolling, plus existing AI workflow and replacement regressions. Normal and minimum-size screenshots are inspected before publication.
