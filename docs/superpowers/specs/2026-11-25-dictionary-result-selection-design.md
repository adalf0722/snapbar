# 字典結果選字與複製

延續已確認的一般結果操作規則，將相同修正套用到使用者回報的字典視窗。

- 使用單一文件閱讀器呈現詞典來源、詞頭及釋義，保留詞性強調、分組與緊湊高度，支援跨組選取。
- 顯示時不搶焦點，點入文字才啟用視窗；支援拖選、Ctrl+A 與 Ctrl+C。
- 底部按鈕有選取時複製所選文字，沒有選取時複製完整原始查詢結果，保留來源標頭。
- 未釘住的視窗在自身取得前景時繼續開啟；來源候選及寫回權限仍正常失效。之後切到其他視窗就關閉，即使來源候選已清除也會檢查。
- 釘住的結果繼續在切換視窗後保留；缺少詞典等訊息頁維持原有設定入口。

以可丟棄離線詞典驗證實際拖曳及底部按鈕點擊、鍵盤全選與複製、跨組選取、原始全文精確複製、來源候選失效，以及未釘住／釘住的視窗生命週期。同步回歸一般結果的選字與原文回填安全檢查。
