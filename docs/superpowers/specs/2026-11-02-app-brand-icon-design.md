# SnapBar App 品牌圖示

使用者在三款概念預覽中選定 C（幾何 S），確認定稿後要求套用。

## 視覺與資產

- 以有斜切角的幾何 S 作為共同輪廓。App 使用白色 S、`#3867D6` 藍底與透明圓角。
- 主圖示及深、淺底系統匣圖示位於 `src/SnapBar.App/Assets/Branding/`，保留 SVG 原稿、PNG 預覽與 ICO。
- 每份 ICO 包含 16、20、24、32、40、48、64、128、256 px。小尺寸調整留白並將筆畫對齊像素。

## 套用方式

- `ApplicationIcon` 指定主 ICO，套用至 Windows EXE 與 WPF 預設視窗圖示。
- 系統匣自動偵測模式顯示藍底 S；僅使用快捷鍵模式顯示透明底單色 S。文字提示與選單保留既有狀態說明。
- 單色圖示依 Windows 的 `SystemUsesLightTheme` 選擇深、淺筆畫，不依 App 動作列主題判斷。高對比模式依系統 Window 色選擇。
- Windows 外觀偏好變更後，在 UI dispatcher 更新系統匣圖示；結束時解除系統事件訂閱並釋放圖示。
- ICO 以 WPF 資源內嵌，不依賴套件外的檔案。此變更不改設定格式或選取與剪貼簿流程。

## 設定頁品牌延伸

使用者看過關於頁後，確認在左側頂端與關於頁加入品牌圖示。左側以 24 DIP 圖示、10 DIP 間距接產品名稱；關於頁以 48 DIP 圖示、14 DIP 間距接垂直排列的名稱與版本。其他功能導覽圖示維持原樣。

兩處共用內嵌 256 px 主圖 PNG，使用高品質縮放；品牌圖示不接收點擊或鍵盤焦點。保留版本完整資訊的 tooltip、原有診斷區與結束按鈕。外觀套件保存標準及最小視窗關於頁截圖供目視確認。

## 驗證

檢查全部 27 個 ICO 圖框的尺寸與透明通道，執行 repository checks 與完整 Release 桌面套件後，依現有發布流程更新 `artifacts/p0`。實際啟動確認視窗圖示與既有設定正常；跨螢幕混合 DPI、Windows 主題切換及高對比切換另列人工驗證限制，不以概念預覽代替真實桌面驗證。
