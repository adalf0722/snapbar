# OCR 共用動作設計

日期：2026-11-08。使用者已同意喬布斯視角提出的共用動作方向，以及馬斯克視角補充的獨立來源驗證、完整輸出設定與擴展案例驗收，並以「同意，go」及「請實作」授權繼續。2026-11-09 已完成實作與共用動作驗收，最終規格／品質審查通過；分批測試、既有原生捲動測試失敗及硬體限制詳見 `docs/p0-validation.md`，不代表完整 Release 驗證通過。

## 目標與方案

新增一個動作，選字與 OCR 都能使用，只需設定與維護一次。

採用既有動作目錄與執行能力，加上來源各自的驗證及套用介面。相較於複製一套 OCR 動作設定，此方案避免名稱、隱藏、腳本及輸出行為分歧；相較於直接把 OCR 偽裝成外部選取，此方案不需要放寬前景、焦點及 Probe 驗證。只新增搜尋等少數固定按鈕，無法滿足此次共用自訂動作的目標。

## 現況

- `ActionCatalog` 管理內建動作、自訂動作、主列／更多／隱藏配置與最近使用。
- `OcrResultWindow` 目前直接實作複製、搜尋及重新框選，尚未接上共用動作。
- `SelectionController.CustomActions.cs` 目前同時處理外部來源驗證、`CustomActionRunner` 呼叫、輸出分派與外部貼回；不能直接繞過來源驗證供 OCR 使用。
- AI 視窗使用 `SelectionSnapshot` 與 `SessionPolicy.CanWrite` 判定可套用性，需增加明確的本機文字目標介面，不能捏造外部視窗或可寫權限。

## 成功結果卡與更多選單

成功後底部顯示「複製文字」、「重新框選」、「⋯ 更多」；搜尋移入更多。辨識中、空結果與辨識失敗卡維持既有行為，不顯示更多。成功後將文字改為空白時，依各動作是否需要輸入決定可用性，不一律停用不需要文字的自訂動作。

更多從同一份 `ActionSettings` 讀取所有未隱藏且符合 OCR 情境的動作，包含原本釘在主工具列上的動作；複製已在卡片外，不重複列出。剪下與貼上保留文字編輯框的標準鍵盤／右鍵操作，不放入此選單，也不導向截圖來源程式。OCR 本身與重新框選不再重複列為共用文字動作。

沿用既有動作名稱、圖示、最近使用排序及選單搜尋／鍵盤操作模式，不建立 OCR 專屬動作設定。主列與更多配置仍控制原選字工具列；OCR 的單一更多入口收納兩者，不改寫原配置。不適用項目停用並提供原因，例如文字不是連結或無法查詞；使用者隱藏的項目完全不顯示。底部提供「管理動作」進入既有設定。

開啟更多時重新讀取最新動作設定，執行前再次確認動作存在、未隱藏且設定版本一致；設定已移除或修改時不執行舊選單中的內容，提示重新選擇。最近使用紀錄沿用既有保存路徑，保存失敗不得假裝已儲存，不新增另一份 OCR 偏好。

## 輸入與來源驗證

開啟選單不得清除編輯框的選取。執行動作時使用目前編輯後文字：有反白取反白範圍，否則取全文；不使用最初辨識文字或截圖背後程式的內容。`UseSelection = false` 仍傳入空字串，不擅自加上 OCR 文字。

每次動作建立不可變輸入票據，包含結果卡身分、文字版本、輸入文字、原選取範圍及取全文／反白模式。輸入票據與文字版本是短期記憶體資料，不寫入偏好或日誌。無文字輸入需求的動作仍有視窗生命週期票據。

OCR 驗證只檢查結果卡仍存在、未重選／關閉、工作票據仍有效，並在有文字輸入或套用需求時核對文字版本與目標範圍。不得因視窗控制代碼重用而接受舊結果。使用者修改文字、選取另一範圍、關閉卡片或重新框選後，舊票據不得產生自動剪貼簿寫入、開啟目的地或文字替換；可保留已取得的輸出供明確複製，並說明原套用目標已變更。

外部選字沿用原本密碼欄位拒絕、前景／焦點與候選身分重驗證、Probe／剪貼簿租期及過期結果取消；OCR 不取得外部輸入模擬或貼回權限。共用執行不代表共用來源授權。

## 動作與輸出契約

搜尋、開啟連結、檔案位置與查詞共用既有解析／適用性政策及實際服務。目的地需在作用發生前重驗輸入票據。檔案位置沿用既有路徑準備、逾時與 Shell 操作保護，不直接拼接 shell 指令。查詞沿用啟用詞典、詞形處理、分來源顯示與既有管理入口。

AI 共用既有服務設定、憑證、命令與結果 UI。OCR 的套用操作明確標示「套用到辨識文字」；只在本機輸入票據仍有效且使用者主動套用時生效。外部來源的套用標示及權限保持原行為，不能因新增 OCR 適配而允許原本唯讀的外部來源寫入。

自訂網址、PowerShell、JavaScript 共用既有內容、`InterpreterPath`、`TimeoutSeconds`、`UseSelection`、錯誤診斷與執行器，所有 `ActionOutput` 保持原設定語意：

| 輸出設定 | OCR 行為 |
| --- | --- |
| `None` | 不呈現輸出內容，顯示完成狀態；錯誤仍可診斷 |
| `Clipboard` | 票據有效才寫入腳本輸出；剪貼簿忙碌時保留可取得的輸出並提示失敗 |
| `ReplaceSelection` | 票據有效才替換動作啟動時的 OCR 反白範圍；無反白時替換全文，不自動貼入外部程式 |
| `Hud` | 沿用短暫提示及既有錯誤呈現，不擅自變成文字替換 |
| `Window` | 沿用文字結果視窗，可複製；手動套用時重驗 OCR 目標 |
| `Markdown` | 沿用 Markdown 結果呈現，可複製；手動套用時重驗 OCR 目標 |

自訂動作設定為替換時，執行前讓使用者可辨識會「替換辨識文字」，保留設定原本的自動替換語意；AI 則維持既有主動套用流程。替換本機文字不借道剪貼簿，因此不得順便覆蓋剪貼簿內容。套用後保留標準 Undo 能力與編輯焦點。

已執行的網址導覽、腳本自身的外部副作用或剪貼簿成功寫入不宣稱可回復。取消保證釋放本次擁有的工作、拒絕後續輸出作用；不能靠取消 UI 宣稱撤銷腳本已造成的變更。不得額外輸出選取文字、腳本輸入或剪貼簿內容至日誌。

## 執行生命週期與共用邊界

同一張 OCR 卡同時只執行一個動作，顯示進度與取消入口，不排入重複點擊。編輯文字維持可用；編輯或切換目標範圍使舊票據失效。關閉／重新框選時取消並解除所擁有工作及子視窗關聯；較晚完成的舊工作不能改寫新卡片或覆蓋新工作的忙碌狀態。腳本逾時沿用其個別設定，不套用 OCR 辨識的 15 秒逾時。

按下更多後 Esc 先關閉選單並返回編輯框，第二次 Esc 才關閉卡片；動作執行中則先依明確的取消入口取消工作。選單需支援滑鼠、Tab、方向鍵及 Enter，窄工作區可捲動，開啟與關閉不破壞編輯框選取。

共用動作目錄、輸入處理、執行器、輸出分派政策與結果呈現；來源適配器各自負責驗證、取消及套用。不得在 OCR 中複製另一份完整 `ActionOutput` 分派邏輯，也不得讓現有 `SelectionController` 充滿以 OCR 來源字串跳過安全檢查的例外。只抽出此次兩種來源確實共用的部分，不建立任意外掛架構或改寫所有視窗。

所有新增操作與錯誤訊息提供繁中／英文資源。既有開啟視窗語言快照規則、使用者自訂名稱與 OCR／AI 原文保持不變；新增穩定 AutomationId 與可讀取操作名稱。

## 驗收與交付

1. 新增一個自訂網址動作，原選字與 OCR 都可執行；修改名稱、圖示、內容、隱藏及移除後兩邊一致，未新增第二份設定。測試注入導覽器，不實際傳送測試以外的文字。
2. OCR 全文、反白、校正後文字及 `UseSelection = false` 的輸入正確；開啟／關閉更多不丟失選取，不適用動作不能執行，已隱藏動作不可透過舊選單執行。
3. PowerShell 與 JavaScript 共用執行器；各輸出模式、指定 interpreter、取消與個別逾時符合既有設定。測試使用拋棄式腳本，不接觸使用者檔案。
4. AI 共用服務與命令，以受控回應驗證 OCR 套用成功、文字／範圍已變更時拒絕、卡片關閉及重選後拒絕；不呼叫真實付費服務。
5. 同一份輸出可以替換原反白或全文；本機替換保持剪貼簿不變並可 Undo。舊結果不能寫入新卡片，忙碌狀態、取消及錯誤均可恢復，下一次動作可成功。
6. 既有外部來源的不可寫、焦點變更、候選過期、剪貼簿租期及拒絕路徑回歸通過，不以單純套用 delegate 或 UI 開啟測試代替安全驗證。
7. 保存成功結果的更多選單、搜尋／不適用狀態、執行中與 OCR 套用結果截圖；使用拋棄式 fixture 遮蔽使用者桌面。測試繁中、英文及受限工作區；未具備的混合 DPI／多螢幕環境明確列為未驗證。
8. 執行 `scripts/check.ps1` 與計畫中依改動選定的 OCR、動作、執行器、AI、語言及選字安全桌面套件。測試及建置前確認 App／Probe 已正常退出，不強制關閉目前開發版程序。
9. 實作完成新增唯一命名的繁中更新說明，在 `docs/p0-validation.md` 記錄實際測試與截圖路徑；Markdown／JSON 使用 UTF-8 無 BOM 並嚴格解碼確認。此次不包含推送、公開發布或替換安裝版。
