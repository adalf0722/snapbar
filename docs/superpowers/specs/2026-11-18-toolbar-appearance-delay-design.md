# 動作列出現延遲控制

日期：2026-11-18

## 目的與已同意方向

讓使用者微調自動動作列的出現時機。提供同步滑桿、毫秒輸入框與還原預設；只影響自動顯示，不延後快捷鍵、直接動作或自動複製。

本文件完成對現有程式的核對，待使用者審閱後進入實作計畫。

## 現況與方案選擇

`SelectionController.CaptureAsync` 在滑鼠選取時先等 120 毫秒，快捷鍵先等 40 毫秒，才開始讀取。成功後先處理自動複製與直接動作，再呼叫 `popup.Present`。一般設定已有文字選取群組與自動顯示開關；設定透過 `ApplicationSettings` 與 `SettingsStore` 保存。

曾比較三種方式：固定快速／標準／稍慢、把現有讀取前等待改為可調值、獨立控制顯示期限。採用第三種搭配精細控制：固定選項不能滿足微調需求，改動讀取等待則會影響自動複製與讀取穩定性。

## 設定介面

- 在一般設定的文字選取群組、自動顯示開關下方新增「動作列出現延遲」。
- 同列提供滑桿、整數輸入框、「毫秒」單位與「還原預設」按鈕，窄視窗可換行，不能裁切或造成水平捲動。
- 範圍為 0–2,000 毫秒，預設 120 毫秒。滑桿步進 10 毫秒，鍵盤方向鍵步進 1 毫秒；輸入框可輸入任意合法整數，不因滑桿步進而被取整。
- 說明文字：「選取文字後，至少等待指定時間再顯示。0 表示選取內容準備好後立即顯示。」實際顯示仍受讀取、安全檢查及系統排程影響，不承諾 1 毫秒執行精度。
- 關閉自動顯示時停用這列控制項，保留原值；重新開啟後沿用。
- 介面、錯誤訊息、提示與無障礙名稱同時提供繁體中文與英文，遵循既有語言切換與版面樣式。

## 編輯與保存

- 拖曳時即時同步顯示數值，放開滑桿時保存；滑桿鍵盤調整依短暫合併更新保存，避免每次移動都寫入磁碟。
- 輸入框允許暫時空白，按 Enter 或失焦才驗證與保存；Escape 回復已保存值。與滑桿互動時取消未提交的輸入草稿，採用滑桿的新值。
- 僅接受 0–2,000 的整數；空白、小數、負數、超界或無法解析的內容不保存，顯示明確提示並保留已生效設定。失焦時回復已保存值，錯誤提示保留至下次合法操作。
- 保存成功才更新執行中的偏好；失敗時兩個控制項回復最後成功值並顯示可重試提示，不能顯示為已保存。
- 還原預設保存 120 毫秒。相同值不重複保存。
- 新增獨立整數偏好 `ToolbarAppearanceDelayMilliseconds`，沿用目前 schema 8 的可選欄位擴充方式。舊檔缺欄位預設 120；合法 JSON 中的超界整數限制至範圍內。錯誤型別沿用既有無效設定保護，不能覆寫原檔。其他偏好保持完整。

## 計時與流程

1. 在輸入監聽收到有效滑鼠選取事件時，以單調時鐘記錄起點；透過 dispatcher 排隊的耗時也計入。該次請求固定採用當下已保存的延遲值。
2. 保留目前讀取前 120 毫秒等待、UIA／剪貼簿擷取、重試與自動複製行為。讀取及複製耗時都計入顯示期限，不另加完整延遲。
3. 僅對將要自動顯示的動作列等待剩餘時間：`max(0, 設定延遲 - 自事件起已經過時間)`。例如設定 300 毫秒、準備花 180 毫秒，只再等約 120 毫秒；準備花 450 毫秒則不再等。
4. 自動複製成功的回饋在既有處理完成點顯示，不移到新增等待之後。自動顯示關閉時不進入顯示等待。
5. 等待可取消，不能阻塞 UI 執行緒。快捷鍵呼叫動作列、直接動作與 OCR 路徑不套用此偏好。
6. 設定變更只影響之後的新選取請求；設定視窗取得焦點時沿用既有取消規則，不重排舊請求。

## 安全與責任邊界

Core 承擔範圍、預設值、剩餘時間計算與保存正規化；App 承擔控制項、保存回呼及非同步顯示調度。Windows 與 Probe 的擷取策略、動作權限及 lease 不因本功能改變。

新增等待期間不得把尚未顯示的選取內容暴露給動作列的按鍵處理或沿用可見工具列的滑鼠離開判斷。保留 generation ticket 與取消 token，避免舊等待覆蓋新選取。自動複製回饋的顯示或關閉也不能誤取消同次仍待顯示的動作列。

新的選取、取消選取、按鍵、點擊、捲動、切換視窗、關閉自動顯示、停止或退出均需取消舊請求。顯示前再次檢查 ticket、取消狀態、自動顯示開關與來源視窗／焦點；對經過新增等待的選取，沿用來源適用的既有 revalidation 檢查候選身分與內容，失敗就放棄顯示。不能只因文字相同就接受另一個候選。

密碼欄位拒絕、應用程式排除與剪貼簿序號保護維持有效。不為延遲擴大 lease 或放寬動作權限，不在日誌寫入選取或剪貼簿文字。

## 驗證與交付

- Core runner：預設與邊界、舊設定載入、保存往返、超界正規化、其他偏好保留，以及用可控制時間驗證剩餘時間計算。
- 桌面設定測試：同步、精確整數、無效草稿、Enter／失焦／Escape、還原、保存失敗回復、開關停用、重新載入持久化及雙語可用性。
- 桌面行為測試：快速與慢速讀取不重複疊加延遲，重新選取與焦點切換取消舊結果，取消後不閃現，較長延遲下自動複製與回饋仍及時，快捷鍵與直接動作不受影響。時間測試使用合理容差，不能要求 Windows 精準到毫秒。
- 特別驗證 2,000 毫秒等待期間的候選失效、同視窗焦點變化與回饋視窗互動。
- 執行日常 `scripts/check.ps1` 及相關桌面套件，依現有規範保存驗證紀錄與介面截圖。桌面套件須在 SnapBar 正常退出後執行。
- 實作交付新增唯一命名的繁體中文 release note，包含用途、調整方式、範圍、0 值語意與啟動前提。本階段僅規格，不建置或發布套件。
