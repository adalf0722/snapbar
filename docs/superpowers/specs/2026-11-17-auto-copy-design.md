# 自動複製設計

日期：2026-11-17。使用者已同意功能方向；本文件供實作前確認。

## 目標與操作

讓使用者在選取文字後省去複製動作，同時明確控制何時覆寫剪貼簿。自動複製與自動顯示工具列各自控制，不互為啟用條件。

- 「自動複製」預設關閉；既有設定升級後也保持關閉。
- 觸發方式預設為「按住 Ctrl 選取才複製」，另可切換「選取即複製」。
- 在「選取即複製」模式，按住 Ctrl 選取會略過本次自動複製。
- 「顯示複製提示」預設開啟，能獨立關閉；不影響複製是否執行。
- 設定保存至既有設定檔，重新啟動後保留；保存失敗時回復畫面與執行中的舊值並顯示失敗訊息。

第一版固定使用 Ctrl，不增加輔助鍵選擇器。設定文字直接顯示所選模式的 Ctrl 用法。SnapBar 不攔截或吞掉 Ctrl，來源程式仍收到完整的鍵盤及滑鼠事件；若來源程式用 Ctrl 改變選取行為，以最後驗證成功的文字選取為準。

## 範圍

支援既有滑鼠拖選、雙擊及連續點擊所產生的選取事件。不新增鍵盤選取、OCR、自訂動作結果或程式設定選取的監聽。不恢復已棄用的全域複製快捷鍵。不新增剪貼簿歷史、復原、音效或每個應用程式獨立的自動複製設定。

自動複製遵守現有自動擷取的應用程式排除清單。通用剪貼簿相容性與 Sublime 相容性維持既有偏好及首次設定要求；新功能不得自行啟用任何相容性。

## 事件與生命週期

1. 滑鼠完成選取時記錄 Ctrl 狀態、座標及目標身分，依模式決定本次是否要求自動複製。只有 Ctrl 可以參與觸發判斷；若同時按住 Alt、Shift 或 Windows 鍵，略過本次自動複製。
2. 自動複製關閉或本次不符觸發條件時，仍依既有工具列開關執行原流程。工具列關閉但本次需要複製時，仍可擷取文字。
3. 需要複製時先等待所有輔助鍵放開，最多 600 毫秒，避免在按住 Ctrl 時注入相容性讀取操作。判斷使用滑鼠放開時的快照，後續放開 Ctrl 不改變本次模式判斷。
4. 使用既有擷取管線讀取選取。只對成功且非空的文字選取繼續處理。按鍵放開可讓等待繼續；新的按鍵按下、點擊、捲動、選取、前景目標改變、功能關閉、偏好改變或程式結束，均使舊請求失效。
5. 寫入前再次驗證候選身分、焦點、前景視窗、選取內容及請求世代。任何不一致均取消，不寫入先前文字。
6. 每個有效選取事件最多執行一次自動複製；同一次擷取供工具列與自動複製共用，不各發一個相互取消的請求。不以文字內容全域去重，使用者再次選取相同文字仍可複製。
7. 若仍需要顯示工具列，在複製成功或失敗後均維持正常呈現；自動複製不因沿用直接複製動作而關閉工具列或改變動作排序。

600 毫秒是等待放鍵的獨立上限，不延長既有 probe timeout 或候選 lease；等待結束後才擷取新的候選。超時直接略過複製。

## 剪貼簿與安全

保留密碼欄位拒絕、來源／候選身分、焦點及前景檢查、過期結果取消，不降低現有動作權限。自動複製是讀取選取後寫入 Unicode 純文字，不要求欄位可編輯。

寫入必須與既有手動複製共用已驗證的寫入機制，但自動觸發、提示與工具列生命週期另行控制。複製前後不記錄文字或剪貼簿內容。

讀取相容性來源可能暫時使用剪貼簿，必須保留既有備份、還原、序號及競態政策。最終寫入前應確保使用者或其他程式在擷取與驗證期間的新剪貼簿內容不會被舊請求覆寫：序號以既有讀取交易的受控變動為準，外部變動使此次自動複製取消。不可把相容性讀取自身的備份還原誤判為外部變動，也不可略過外部變動檢查。

剪貼簿忙碌、等待超時、驗證失敗、相容性停用或來源不支援時，安靜略過，保留既有診斷狀態，不顯示成功提示，不彈出錯誤對話框。

## 設定與提示呈現

一般設定新增一張自動複製卡片：主開關、觸發方式、對應的 Ctrl 操作說明及「顯示複製提示」開關。主開關關閉時，從屬控制項停用但保留原值。沿用現有卡片、捲動、鍵盤操作與 AutomationId 慣例，提供繁體中文及英文資源。

成功完成剪貼簿寫入且仍屬目前請求時，顯示「已複製 ✓」／「Copied ✓」。提示位於選取結束位置附近，避開游標、選取範圍及工具列，限制在目前螢幕工作區內，支援不同 DPI；不取得焦點、不接收滑鼠輸入、不顯示文字內容。

提示持續約 900 毫秒。新提示取代舊提示；新互動、目標改變、關閉提示或程式結束時立即收起，不堆疊視窗。關閉提示選項也會取消尚未顯示的成功提示，但不取消已合法完成的剪貼簿寫入。

## 元件責任

- Core：新增設定值與正規化、觸發判斷政策；保留舊設定及相容性偏好。
- Windows：選取事件附帶輔助鍵快照；沿用原生焦點、剪貼簿交易與競態檢查。
- App：設定持久化、自動複製協調、取消及工具列共存；以獨立提示視窗負責短暫回饋，避免進一步擴大主選取控制器的責任。
- Probe：沿用既有擷取與驗證契約，不放寬密碼或候選驗證。若整合時必須變更契約，相關 Core、Windows、Probe 與 App 檢查一併更新。

## 驗收

Core console runner 驗證預設、舊設定讀取、保存往返、無效模式回復到按 Ctrl 模式，以及兩種模式與輔助鍵組合的判斷。

Windows console runner 與桌面 fixture 驗證：

- 自動複製與工具列開關四種組合；觸發及略過均正確，手動複製不退化。
- 按住 Ctrl 拖選後放開、雙擊、連續選取、等待超時及等待期間新互動。
- 密碼欄位、空選取、排除程式、焦點切換、過期結果、剪貼簿被外部更新及忙碌。
- 通用／Sublime 相容性偏好受尊重；相容性讀取備份還原後仍能合法複製。
- 提示開關、生存時間、不搶焦點、不攔截滑鼠、連續成功不堆疊、多螢幕與 DPI 邊界。
- 設定保存失敗回復、重新啟動保留、英文／繁中資源與小視窗捲動。

實作後執行 scripts/check.ps1 及相關桌面套件；記錄實際驗證與尚未完成的跨應用程式／DPI 結果至 docs/p0-validation.md，新增繁中 release-notes JSON。此功能不包含發布或替換 artifacts/p0。
