# 一般設定頁比例與可讀性

使用者於 2026-11-03 依截圖審閱同意三項調整，並以「go」授權執行。

一般頁維持既有側欄、配色、圓角及視窗尺寸。快捷鍵卡片左側為「叫出動作列」與用途說明，右側同排排列鍵位及「更換」；自訂鍵位的「恢復預設」也在操作側。平常不顯示編輯說明或操作列，只有錄製或錯誤時展開說明及儲存／取消。每顆鍵帽保留邊框，外層矩形框移除；錄製欄仍有可見鍵盤焦點底線。成功保存後回到精簡模式，錯誤不收起，取消／失焦／離頁行為沿用。

登入啟動正常副標統一為「登入後在系統匣待命。」，由開關表達啟用狀態；系統停用、程式搬動或讀取失敗仍顯示原因與修復入口。一般頁說明文字改為 14 DIP、#4F5968，頁尾改為 13 DIP 的「關閉設定後，SnapBar 會繼續在背景執行。」；不改其他頁的字體規則。

使用既有 Lifecycle、Appearance 與完整 Release 驗證錄製／取消／儲存及版面，檢查正常、小視窗、錄製與錯誤截圖。發布沿用現行來源指紋、桌面證據、App／Probe 乾淨環境 smoke 與 staging 保護；登入啟動位置及使用者偏好保持不變。
