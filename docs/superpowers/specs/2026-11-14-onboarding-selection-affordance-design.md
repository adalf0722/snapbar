# 使用入門選字辨識設計

日期：2026-11-14。使用者提供畫面並要求消除可選對象的歧義，將這個首次操作體驗進一步優化。

狀態：已實作。Core 與相關桌面套件通過，已檢閱真實選取的渲染圖並進行實際滑鼠拖曳；證據與驗收限制見 `docs/p0-validation.md`。

## 問題與取捨

原本「試著選取這段文字」和教材、快捷鍵都位於同一張白卡，指示中的「這段」會讓人把提示當成教材。僅改提示文字仍保留多個對象；讓提示也可選則把操作說明混入練習。採用直接刪除卡內提示、分開教材與指引的做法。

## 決定

白色可選表面只包含真正的唯讀教材 TextBox。操作說明在表面上方，明確說「在下方句子上拖曳，選取幾個字」；快捷鍵與搜尋指引移至表面外下方。教材表面使用 I-beam 游標、輕量滑入色、可見聚焦邊界，真實反白保持 Windows 選取樣式，不預先畫假選取。

真實 SelectionChanged 只更新本機下一步提示與邊界色。沒有選字時提示「選好後按」，有選字時提示「現在按」。保留固定寬度的提示位置，避免反白時字句移動。清除選字後還原提示；完成狀態仍必須來自真正搜尋啟動成功事件，不因選取而完成、不新增 IPC 或持久化內容。

維持既有完成偏好、快捷鍵衝突處理、語言切換、略過返回設定與完成退回系統匣。小工作區仍以主內容捲動、固定底部操作處理。資料傳送說明維持可讀，產品日誌不記錄選字。

## 驗收

卡內只有教材，說明／快捷鍵位於可選表面外；游標與聚焦提示清楚。選字／取消選字能更新下一步，且不製造完成事件。繁中、英文、真實 UIA／工具列搜尋、完成、錯誤、偏好保存回復與小視窗案例通過；檢閱未選取及真實選取的渲染畫面並開啟開發版供試用。
