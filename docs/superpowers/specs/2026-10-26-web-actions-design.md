# 搜尋與開啟連結

日期：2026-10-26。接續原 P1 已確認的 Search／Open Link 工作包。

## 動作與使用體驗

非空白選取提供「搜尋」；完整 HTTP／HTTPS 網址另顯示「開啟連結」。唯讀文字可用這兩個動作，Cut／Paste 仍依可編輯資格限制。網址只去除首尾空白，不從段落內猜取、不補 scheme；含內部空白、控制字元、反斜線、帳密或其他 scheme 時不提供開啟。動作列保留不搶焦點；按鈕隨內容顯示，較窄工作區可換行。

搜尋預設 `https://www.google.com/search?q={query}`。設定提供可收合的搜尋網址欄位、儲存與恢復預設。範本須為 HTTP／HTTPS，`{query}` 恰好一次且位於 query 部分；選取文字以 UTF-8 percent encoding 替換。網址交給預設瀏覽器，不內嵌瀏覽器。文字與網址不得寫入操作紀錄。

## 驗證與執行

兩個動作都在點擊後走既有重新驗證，確認原程序／前景／選取／代次仍有效。Sublime 走原已明確啟用的一般條件讀取，不要求可編輯；保留其剪貼簿交易與原有競態界線。開啟前再檢查狀態，避免把過期文字送出。原生路徑不改剪貼簿。

只在使用者執行動作時呼叫系統瀏覽器。Windows 端以固定 Uri 及 UseShellExecute 呼叫，不建 shell 命令、不接受檔案或自訂 protocol。啟動失敗回報中性訊息；送出只代表已交給瀏覽器，不宣稱頁面已載入。搜尋範本最多 2048 字元，產出的網址最多 8192 字元；這是本產品限制，不宣稱為所有瀏覽器的上限。

## 設定升級

settings.json 升至 schemaVersion 3，新增 searchUrlTemplate。v1／v2 保留自動偵測及排除清單，補預設搜尋範本；下次變更時保存 v3。無效、損壞、較新版本仍保留原檔並採安全預設。舊程式不得覆寫新版本設定。既有保存上限與原子替換保留。

## 驗證

核心測試涵蓋 Unicode、保留字、換行編碼，範本缺失／重複 placeholder、錯誤位置、scheme、帳密、控制字元、長度、完整／不完整 URL 及設定升級。桌面測試使用獨立唯讀 fixture，透過真實 WPF Click 事件、helper 重新驗證及記錄型啟動器，核對目的網址、按鈕能力、失效取消與錯誤訊息；不將事件測試當作實體滑鼠端到端。預設瀏覽器啟動另以 loopback 測試頁驗證，不把測試文字送往搜尋服務。
