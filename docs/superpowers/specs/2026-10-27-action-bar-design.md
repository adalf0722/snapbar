# SnapBar 動作列與自訂動作設計

日期：2026-10-27。使用者已確認互動視覺稿，並授權依此實作。

## 體驗

動作列維持單排，預設顯示複製、剪下、貼上、搜尋；剪下與貼上只在確認可編輯時出現。完整網址／路徑依情境提供入口。文字數不占一個按鈕。提供深色／淺色、圖示／圖示加文字，最多六個固定動作；狹窄工作區將尾端動作收進更多。

更多面板與動作列共用來源工作階段，展開時不奪取來源焦點。提供名稱／英文別名搜尋、最近五筆、不重複清單、鍵盤上下／Enter／Esc 與釘選。2026-10-30 依使用者對輸入體驗的回報，搜尋欄修正為可點入的原生 TextBox，有文字游標、I 型滑鼠游標、焦點框線及一般文字編輯／輸入法。只有點入搜尋時取得鍵盤焦點。從搜尋選擇動作時，僅在自己的面板仍是前景、原來源身分仍有效時嘗試返回來源，再完整重驗原選取後執行；使用者切到其他 App 即取消，禁止搶回前景。

設定頁的「管理動作」統一管理內建及自訂動作。每列直接選擇「動作列／更多／隱藏」；固定動作可拖曳或上下移動。上方即時預覽。新增的自訂動作預設進入更多。可編輯、複製、刪除及匯入／匯出自訂動作；匯入完整內容預覽後才保存，不會執行。

## 自訂動作

三種類型：HTTP／HTTPS 網址、PowerShell、JavaScript。共同欄位為名稱、圖示、內容；腳本另有執行環境路徑、1–300 秒逾時（預設 10 秒）、輸出模式。網址含一個 `***`，替換為完整 URL encoded 的選取內容，禁止帳密與其他協定。腳本由 `POPCLIP_TEXT` 環境變數取得選取，不拼進程式碼或程序參數。

編輯器以範例文字預覽。網址預覽顯示真正編碼結果；腳本測試只在明確點擊後實際執行，顯示結果／錯誤，可取消。執行腳本以目前使用者權限，儲存或匯入不會執行。缺少 Node.js／指定直譯器、無效逾時、超限輸出、非零結束碼與逾時均顯示明確中性錯誤。

輸出支援不處理、複製、替換原選取、短暫提示、純文字視窗、Markdown 視窗。預設先顯示結果。Markdown 僅本機排版，不執行 HTML、腳本或外部內容。Copy 使用原始輸出。替換前重新驗證來源，並把結果放入剪貼簿再送出貼上；此副作用在編輯器說明。原目標變更、不可編輯、多段或不明狀態時不可替換，保留可複製結果。

## 架構及資料

Core：動作定義、目錄、排序、條件適用性、URL 驗證、匯入／匯出與設定正規化。設定 schema v4 保留 v1–v3 自動偵測、排除 App 和搜尋範本，新增動作設定、外觀及最近使用 ID。原檔無法讀取、版本較新或無效時仍禁止覆蓋。

Windows：可取消的隔離程序執行器，UTF-8 I/O、有上限 stdout／stderr、逾時／取消終止程序樹、暫存腳本在 finally 清除。程序使用固定腳本路徑參數，不經命令殼字串拼接。

App：PopupWindow、ActionSettingsWindow、ActionEditorWindow、ActionResultWindow，與 SelectionController 的動作協調。保留原有手動快捷鍵、Sublime 明確 opt-in、密碼拒絕、來源焦點與範圍重驗、立即輸入失效、generation 取消。結果視窗以不啟用方式顯示，只有原來源仍有效才允許套用。不強制恢復其他視窗的焦點。

## 驗收

Core runner 驗證設定遷移、重複／無效 ID、六個上限、排序／隱藏／最近清單、Unicode URL 編碼與協定限制。Windows runner 驗證腳本真正執行、UTF-8、選取不進參數、非零碼、逾時、取消、輸出上限與暫存清理。原生 UI 驗證唯讀／可編輯／網址／路徑、更多面板來源焦點、操作取消及自訂動作結果。建置及 publish 後更新 artifacts/p0。實體混合 DPI 與第三方 App 全組合仍列人工驗收。
