# 自訂動作結果選字與複製

使用者已確認採用保留 Markdown 排版的方案，讓一般自訂動作結果與 OCR 的選字、複製規則一致。

## 操作

- 一般文字與 Markdown 結果使用既有文件閱讀器，保留資訊排版及長文捲動。
- 點入結果文字時啟用視窗並取得閱讀器焦點，支援滑鼠拖選、Ctrl+A 及 Ctrl+C。
- 有選取時，底部按鈕顯示「複製所選文字」並複製顯示區的選取內容。
- 沒有選取時，按鈕顯示「複製全部」並複製完整原始輸出，包含原始順序與 Markdown 語法。
- 按鈕文字跟隨視窗建立時的介面語言。

## 焦點與安全

結果剛出現時維持不搶焦點。直接操作底部按鈕維持原有焦點策略；點入結果文字才主動啟用視窗。既有控制器在原來源失去前景時使寫回權限失效，不恢復舊候選，不放寬焦點、候選識別或選取重驗規則。OCR、查字典、短暫提示及診斷視窗維持各自原有行為。

## 驗證

使用可丟棄的桌面 fixture 驗證實際拖選、底部按鈕保留選取、Ctrl+A／Ctrl+C、清除選取恢復全文複製、Markdown 排版與原始全文、英文標籤，以及點入結果後拒絕舊來源回填。沿用保留結果、多視窗、延遲完成、有效回填與長文捲動的回歸測試。
