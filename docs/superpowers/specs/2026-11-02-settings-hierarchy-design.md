# 設定全頁視覺層級

日期：2026-11-02。使用者要求其他頁面一併檢查與調整，延續已討論的一般頁修訂。

## 統一規則

- 一般頁只保留自動顯示與快捷鍵兩列設定；移除預覽、管理入口及重複待命說明。快捷鍵使用分開的鍵帽，背景待命留在全域頁尾。正常狀態以低調文字顯示，在一般頁避免重複；初始化與熱鍵錯誤仍明確可達。
- 次要操作按鈕預設就有清楚邊框與白色表面，藍色實心用於主要操作；導覽仍保留選取狀態。圖示釘選有明確控制邊界與選取狀態，展開入口使用有邊界的按鈕樣式。保留鍵盤焦點、停用與滑入／按下狀態。
- 動作頁保留精簡預覽，但明確標示「預覽」，不可執行；不犧牲標準尺寸六列動作可見範圍。依使用者後續實際畫面回饋，刪除上方「動作／搜尋」分頁；搜尋設定改從搜尋動作的「編輯」進入，標題明確寫「編輯搜尋動作」，有返回動作列入口。返回或切頁保留同一份搜尋草稿，動作列的搜尋項目顯示未儲存狀態；儲存、捨棄與退出協調沿用既有契約。
- 「動作列／更多／隱藏」只表示顯示位置，以明確標籤與底線選取樣式呈現，和左側分類的淡色底分開。鍵盤焦點使用獨立虛線標記，不再以點擊後的藍框混淆目前選取。搜尋項目在三種位置都可編輯；主設定宿主提供搜尋編輯入口，獨立動作排列測試宿主仍只管理排列。
- AI 命令的服務設定入口恢復為明確次要按鈕；維持五個初始命令完整可見與精簡計數。AI 服務及搜尋表單加強欄位標籤層級，輔助文字保持次要，保留固定保存列與所有金鑰說明。
- 相容性以兩個有關係的設定列呈現模式與 Sublime 支援；保留首次設定、剪貼簿歷程說明、啟用與停用關係。排除清單空白時顯示明確空狀態；非空時維持局部捲動與選取路徑。
- 關於頁顯示易讀版本，完整組建資訊仍可在診斷區取得；診斷保持預設收合，結束操作維持清楚可達。

## 範圍與驗證

維持現有 schema、保存契約、草稿、復原、退出及選取安全。六頁與搜尋子頁在標準及 480 DIP 受限工作區截圖驗證；回歸控制可存取性、草稿／保存失敗、釘選與排序、相容性及背景待命。實體混合 DPI 仍需另行人工驗證。
