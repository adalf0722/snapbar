# 自訂動作圖示選擇

日期：2026-11-02。使用者已確認僅擴充自訂動作，並同意修正版草圖的名稱旁入口與獨立圖庫互動。

## 範圍與體驗

- 新增及編輯自訂動作時，在名稱旁顯示目前圖示按鈕。按鈕提供「更換圖示」提示、可存取名稱與鍵盤焦點；不顯示圖示識別碼輸入欄。
- 點擊按鈕開啟編輯視窗所擁有的獨立模態圖庫，重用 AI 命令的 Fluent 離線資產、中文與英文搜尋、名稱解析、用途分類、虛擬化網格和鍵盤操作。圖庫使用通用標題「選擇圖示」。
- 圖庫不插入表單底部，不改變表單高度，不推移內容、測試區或儲存按鈕。保留現有動作編輯器的其他欄位、捲動與測試流程。
- 點選圖示後立即關閉圖庫並更新編輯草稿的預覽；關閉、取消或 Escape 不改動原選擇。返回時焦點回到圖示按鈕，其他草稿完整保留。
- 儲存動作後才更新正式設定。取消動作編輯則捨棄本次圖示變更。內建動作圖示、AI 命令資料及其他動作偏好不變。

## 共用元件與資料流

- 將既有 AI 圖示目錄、呈現及選擇器作為共用能力使用；命令的出廠預設圖示判定仍只適用 AI 命令，不套用至自訂動作。避免建立第二份字型、圖示目錄或搜尋邏輯。
- 圖示選擇器回傳識別碼至編輯器的暫存狀態，儲存時寫入既有 `CustomActionDefinition.Icon`；不新增設定檔或額外圖示覆寫表。
- 只有自訂動作的呈現路徑使用支援 Fluent 與舊圖示的呈現器，涵蓋設定清單、設定預覽、實際動作列與更多選單。一般控制項與內建動作的圖示保持原樣。
- 使用者明確選擇的圖示在切換網址、PowerShell、JavaScript 類型時保留。未明確選擇時沿用現有網址／腳本的預設圖示行為；編輯既有動作保留其圖示。

## 保存與相容性

- 移除正規化、保存及匯入／匯出流程只允許 13 個舊圖示的限制，讓正式 Fluent 識別碼可往返而不被替換為星芒。Core 的識別碼政策不依賴 WPF 或載入字型；圖庫解析及實際繪製由 App 負責。
- 舊識別碼如 `globe`、`terminal` 保持原有圖形語意；新增選擇保存正式 Fluent 識別碼，明確選擇舊圖示時支援 `legacy:` 前綴。
- 圖示識別碼限制為最多 128 個 ASCII 字元，僅允許英文字母、數字、底線、連字號與冒號。未知但符合此格式的既有或匯入識別碼保留，畫面以星芒替代，不因編輯其他欄位而重設；空值或格式不合法的資料正規化為既有星芒預設。
- 沿用既有匯出版本與設定結構。舊版 SnapBar 對新圖示可能退回星芒，不宣稱舊版具有 Fluent 圖示呈現能力。
- 設定寫入失敗時沿用既有明確提示，不將失敗顯示為已保存。不得影響選取來源驗證、動作權限或腳本執行規則。

## 驗證

- 核心 runner 驗證舊識別碼、新 Fluent 識別碼、明確 legacy 識別碼及未知合法識別碼的正規化、保存、匯入／匯出往返，以及不合法格式與長度的替代行為。
- 桌面案例驗證新增與編輯入口、圖庫搜尋和分類、選取、取消、Escape、焦點返回、動作類型切換及取消編輯時的草稿契約；確認原表單高度與內容位置不因開啟圖庫改變。
- 檢查設定清單、預覽、深淺色實際動作列和更多選單的圖示一致性，涵蓋僅圖示模式、鍵盤操作及小工作區；確認內建動作與既有 AI 圖示操作保持原行為。
- 執行 `scripts/check.ps1` 與相關桌面案例，記錄實際完成的驗證。若後續要求發佈，再依專案流程取得當前原始碼的 Release 證據並發佈；本設計不自動要求發佈。

## 不包含

自訂圖片上傳、圖示顏色設定、內建動作圖示更換，以及其他設定版面改造。
