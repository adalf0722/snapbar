# 自訂動作刪除與復原

使用者已確認採用刪除後直接顯示「已刪除『動作名稱』〔復原〕」的方案。

- 移除「我的動作」上方選單中的「復原刪除」。
- 在視窗底部保留最近一次刪除的動作名稱與復原按鈕；一般設定變更不會清除提示。
- 復原成功、下一次刪除或關閉視窗後，原提示失效。不增加跨次啟動的回收站。
- 只暫存被刪除的動作、顯示位置與該位置中的索引。復原合併至目前設定，保留之後新增、編輯、排序、主題、標籤及最近使用記錄的變更。
- 優先回到原顯示位置和索引；動作列已滿六個時改放更多選單並提示原因，不移動其他動作。
- 已有同識別碼或自訂動作已滿 32 個時拒絕復原，保留提示並顯示原因。
- 儲存失敗時維持既有「本次已生效」行為，同時保留失敗警告。

Core 測試驗證合併、容量、位置與身分限制；Layout 桌面測試驗證實際按鈕事件、提示、持久化、關閉視窗與儲存失敗。UI 截圖由現有測試入口產生。

## 匯入入口整理

使用者接續確認將頂部只剩匯入的「⋯」改為直接顯示「匯入…」次要按鈕，位於藍色「＋ 新增動作」左側。點擊直接開啟現有檔案選擇及匯入預覽流程。每個動作列項目的「⋯」選單維持原有用途。
