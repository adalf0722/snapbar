# 動作拖曳與右鍵選單

使用者已確認採用抓取手掌游標、動作列與更多之間雙向拖曳，以及精簡右鍵選單，並授權直接實作。

名稱與拖曳把手顯示張開手掌，開始拖曳後顯示握住手掌；禁止放置時保留禁止游標。按鈕、下拉選單與開關不啟動拖曳。維持系統拖曳距離門檻與 Esc 取消。

動作列支援列上方與下方的插入提示。更多維持原有固定順序，拖入時以區域高亮提示。區域標題與空白提示亦可接收拖曳。搜尋期間停用拖曳與排序，保留位置選單。只接受同一設定面板發起的動作拖曳。

拖曳與右鍵操作沿用 ActionCatalog 的容量與顯示規則，不改變顯示開關。九個顯示項目滿額時拒絕搬入，提供原因並保留設定。放開才儲存，不在拖過時改設定。

右鍵選單提供移至另一區、顯示或隱藏，以及適用的編輯入口；自訂動作沿用複製、匯出、刪除與復原。既有位置下拉選單、排序按鈕與鍵盤操作保留。繁中與英文同步。

驗證涵蓋雙向搬移、插入位置、空白區域、來源隔離、取消、容量拒絕、隱藏狀態保存、右鍵與鍵盤選單。記錄測試結果與一般、窄視窗截圖。不調整選取文字、剪貼簿、安全驗證及執行權限。
