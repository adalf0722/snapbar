# 動作清單與顯示開關

使用者已確認採用統一清單與膠囊形顯示開關。動作列與更多同頁分區顯示，移除原本三個位置分頁，不新增篩選列或批次功能。保留搜尋，搜尋期間停用排序。

每個動作分別保存顯示狀態與位置。位置只有動作列、更多；關閉顯示後仍留在原區域，名稱變淡，保留原位置與排序，仍可編輯。重新開啟恢復原位。已顯示的動作列最多九項，開啟超額時拒絕變更並提示，不自動搬移其他動作。預覽只呈現已顯示動作。

舊 Hidden 設定轉成更多位置且顯示關閉，避免更新後意外出現。新欄位預設顯示，舊的其他設定保持原行為。沿用既有隱藏動作的執行限制與最近使用清理規則；不調整選取、安全驗證或快捷鍵授權。

Core 負責遷移、容量、顯示切換與刪除復原；App 使用既有 Switch 樣式呈現開關，保留鍵盤焦點與可讀名稱。繁中、英文資源同步更新。

驗證涵蓋舊設定遷移、儲存重讀、顯示切換的位置與排序、容量拒絕、刪除復原、選單排除，以及統一清單、搜尋與鍵盤操作。以桌面測試產生實際截圖，檢視一般及窄視窗。
