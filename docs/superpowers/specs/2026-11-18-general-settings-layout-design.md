# 一般設定資訊層級

使用者已同意「精簡主畫面＋按需展開」方向。目標是在原有 980 × 720 設定視窗中掃完主要選項，同時保留小視窗、文字放大與展開內容的捲動能力。

- 基本設定包含語言與登入啟動；選取與複製包含動作列與自動複製；文字辨識包含 OCR 語言優先順序。各組共用白色容器與細分隔線。
- 自動複製的剪貼簿覆寫提醒直接顯示。啟用後顯示觸發方式、預設收合的操作說明與進階選項；停用後收起附屬設定，不重設模式或提示偏好。
- Ctrl 操作方式與 Sublime 特例保留在操作說明，複製提示開關移至進階選項。使用支援鍵盤操作與焦點樣式的既有 Expander。
- 登入啟動的一般狀態不重複說明。程式位置變更、系統封鎖、無法讀取與操作失敗仍直接顯示。自動複製儲存失敗仍回復原值並直接顯示錯誤。
- 英文與繁中同步提供分組、操作說明與提醒。僅改呈現，不改選取安全政策或儲存格式。

驗證：Release 建置與 Core runner；Appearance 驗證預設／啟用／展開／小視窗及雙語截圖；AutoCopy 驗證儲存回復及原有操作行為；Language 驗證資源切換。發布說明另存新雙語 JSON，不修改既有發布內容。
