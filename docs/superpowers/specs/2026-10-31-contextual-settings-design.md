# SnapBar 情境設定設計

日期：2026-10-31。使用者已同意前一輪三項優化並授權實作。

## 行為

結果處理說明依目前的輸出模式顯示：不處理、複製、替換原文、短暫提示、文字視窗、Markdown 視窗。只有替換原文說明重新驗證與剪貼簿副作用。測試仍不套用結果至其他 App。

動作管理提供「動作列／更多」切換，固定預覽保持可見，顯示各群組數量。隱藏動作存在時顯示隱藏入口；空的更多顯示清楚空狀態。位置調整、排序、刪除與復原保持原契約。切換只改檢視，不保存設定。

搜尋提供 Google、Bing、自訂；選自訂才顯示網址範本與 {query} 說明。切換選項不立即保存，仍需明確儲存。切回自訂保留尚未儲存的草稿，載入既有自訂範本不改寫內容。

## 選取文字與相容性

腳本新增明確「使用選取文字」選項，預設開啟。關閉後隱藏範例輸入與輸入／輸出比較，不提供插入選取變數；測試及正式執行都將 POPCLIP_TEXT 設為空字串。網址仍必須使用選取文字，不能關閉。動作仍從原選字工作階段啟動，保留密碼拒絕、來源／焦點／原選取重驗及替換寫入限制；此選項不新增無選取的全域執行入口。

設定 schema 升為 5，讀取 1–4 的舊檔時缺少選項預設 true，於記憶體遷移且不自動覆寫。動作檔案版本升為 2，仍可匯入版本 1；版本 1 不得宣告不使用選取文字，避免語意降級。舊版本 App 對新 schema／動作版本會拒絕寫回或匯入。

## 驗證

Core runner 驗證舊版遷移、false 設定往返、匯入版本與網址限制。Windows runner 驗證輸入選項對真實腳本環境變數、編輯器測試及控制器的影響，原選取失效仍取消。UI runner 驗證分頁查找、預設搜尋／自訂草稿、所有輸出模式說明和輸入隱藏狀態。檢視實際 WPF 截圖，完成 Release、自含式發佈與 Probe smoke；使用者現有動作不自動改選項。
