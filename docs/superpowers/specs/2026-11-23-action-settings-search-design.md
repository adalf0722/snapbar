# 動作列設定搜尋

使用者已同意跨分頁搜尋方案。搜尋列固定放在預覽下方，沿用 AI 命令頁的輸入元件，依顯示名稱與原始名稱搜尋內建及自訂動作。空白分隔的關鍵字須全部符合，忽略大小寫。

有關鍵字時搜尋動作列、更多與隱藏的所有動作，顯示符合數量與總數。顯示位置下拉選單直接標示每筆結果的位置，編輯、移動位置與其他既有操作保持可用。位置分頁暫停切換，清除搜尋後回到原先分頁。

搜尋期間不提供拖曳或上下移動排序，並明示清除搜尋後可排序。清除按鈕將焦點留在輸入框。沒有結果時提供明確訊息與清除入口；搜尋不寫入偏好設定，也不改變工具列預覽。

驗證涵蓋繁中與英文、跨位置結果、空結果、關鍵字與大小寫、移動位置後仍保留結果、停用拖曳和排序，以及清除後恢復排序。發布說明提供中英文對應內容。
