# 自訂動作「啟動程式」

## 使用方式

在「管理動作」新增「啟動程式」，設定名稱、選擇本機 `.exe`、逐項填寫命令列參數。可在參數中插入「選取文字」，也可建立只使用固定參數或不帶參數的動作。使用選取文字的動作沿用既有選字入口，也可在 OCR 結果上使用。固定動作沿用既有的無選字執行方式。新增和匯入的動作先放在「更多」，可釘選和匯出。

Everything 的設定範例是選擇 `Everything.exe`，新增 `-search` 和「選取文字」兩個參數。執行後在 Everything 裡查看結果。第一版交付通用啟動能力。先跑腳本再由輸出決定啟動目標，以及在 SnapBar 內查詢 Everything 索引，分別是後續能力。

## 執行與資料

Core 新增動作類型，保存執行檔路徑與有序的參數範本。既有動作與匯入檔沿用原有格式及行為。參數範本在各參數之內展開選取文字，保留參數邊界。Windows 層直接啟動指定的執行檔，不經由命令殼層。啟動成功即完成動作，程式視窗可繼續使用。既有腳本仍由原執行器負責逾時、取消、輸出和子程序清理。

App 層讓選字工具列、OCR 結果和編輯器測試共用啟動路徑。正式執行沿用既有選取來源、密碼欄位和過期操作的驗證。測試按鈕使用範例文字實際啟動。儲存或匯入只寫入設定。預覽顯示解析後的執行檔與個別參數，執行失敗時用介面語言說明原因。選取文字不寫入診斷紀錄。

## 驗收

- 自動驗證參數邊界、選字與無選字動作、既有動作相容性、匯入匯出、取消及無法啟動的結果。
- 在 Windows 桌面驗證 Everything 完全關閉時能開啟，已有背景實例時也能接收搜尋。確認中文字、空格和雙引號符合 Everything 的搜尋語法。
- 用另一個支援命令列參數的程式驗證相同設定流程，並確認既有腳本仍會清理子程序。
- 補上繁體中文發行說明，記錄設定步驟與桌面驗證結果。
