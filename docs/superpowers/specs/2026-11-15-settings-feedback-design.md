# 設定介面操作回饋

使用者已同意依照介面檢視提出的三個方向實作：一致的操作回饋、動作列預覽連動，以及中英文排版與次要操作整理。

## 行為

- 按鈕提供明確的懸停、按下、鍵盤焦點與停用狀態；已固定狀態與懸停可分辨。次要操作保留可見性，但減輕邊框。
- 圖示選擇與更多操作提供提示。一般卡片不暗示整列可點擊。
- 動作列項目與預覽以滑鼠或鍵盤焦點連動；預覽僅供辨識，不執行動作。更多選單中的項目連動至預覽的更多圖示。
- 拖曳把手可辨識，合法落點顯示插入線；排序及位置修改提供結果訊息。保留鍵盤上下移動按鈕。
- 英文位置選單完整顯示，容量提供說明；選單外觀與設定一致。
- AI 命令以一句簡介補充用途；原始自訂文字不翻譯。刪除改為直接按鈕，沿用復原機制。
- 未設定 AI 服務時使用整合提示。編輯介面可展開試用，明示會將範例傳至目前服務；使用草稿指令，不保存、不讀取選取文字或剪貼簿。支援取消及關閉取消，拒絕呈現過期結果。
- 背景執行提醒僅保留於一般頁，例外錯誤仍可顯示。

## 實作與驗證

維持 WPF 與現有偏好儲存架構；回饋集中於共用樣式和小型介面輔助元件。試用重用既有 AI client 與錯誤文案，不更動選取安全或動作執行政策。

驗證 Release 建置、Core runner、Appearance、Language、Layout 與 AI 相關桌面測試。檢視繁中與英文、一般與小視窗的截圖。測試使用隔離偏好及受控服務，禁止真實 API 呼叫。既有未提交變更保持原狀。
