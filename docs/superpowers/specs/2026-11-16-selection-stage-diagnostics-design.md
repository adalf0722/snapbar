# 選字分階段診斷

使用者已同意加入可關閉的分階段診斷，以查明 WeChat 同一訊息成功與失敗交錯的原因。

以環境變數 SNAPBAR_SELECTION_DIAGNOSTICS=1 在啟動時開啟；未設定時不寫檔、不要求 Probe 診斷。每次啟動使用獨立 JSONL，位於 LocalApplicationData/SnapBar/diagnostics，每檔上限 1 MiB。結束診斷版並移除環境變數即可關閉，不改持久偏好。

App 記錄各原生嘗試、回退前驗證、回退讀取、回退後驗證與最終結果，以擷取識別碼串聯。Probe 附加焦點／滑鼠控制項型別 ID、候選數、空選取數、是否支援選字、終點是否位於焦點矩形與停止階段。不包含文字、控制項名稱、剪貼簿內容、聯絡人或例外訊息。檔案錯誤不影響選字。

保持候選順序、等待、重試、安全檢查和寫入政策。以真實微信重做文字內與氣泡邊緣拖曳，用階段判斷修正位置。驗證協定、Core、完整建置和 Probe smoke。相較延長重試或放寬空選取回退，此設計先取得證據並保留安全性。
