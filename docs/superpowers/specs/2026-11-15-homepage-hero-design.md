# 官網三段式介紹

使用者已同意將整頁重新收斂成三段：首屏搜尋、第二段 AI 改寫、第三段下載與首次練習。此設計取代前一版首屏與第二段重複展示相同改寫範例的安排。

## 範圍與內容

- 繁中 `site/index.html` 與英文 `site/en/index.html` 採一致敘事，保留品牌與下載機制。主內容恰有三個主要區段。
- 首屏以「看到想查的字，選起來就能搜尋」說明基本價值，直接演示搜尋，不混入 AI 草稿範例。下載旁交代 Windows x64、免登入下載、ZIP 解壓啟動與未簽章預覽版，說明首次搜尋不需設定 AI。
- 第二段只說明「回覆太囉嗦？選起來，改短一點」，展示原文與縮短結果。交代先預覽、再複製或在可編輯且通過驗證的來源替換；AI 服務、模型、API Key 與可能的費用另行設定。執行指令時才傳送文字。
- 第三段以首次搜尋為起點，依序解壓、啟動內建練習、按畫面提示快捷鍵並搜尋。FAQ 優先回答工具列啟動、自動顯示與系統匣；保留語言、AI 與替換限制說明。自訂動作移至可展開說明，保留 Node.js 與腳本權限資訊。

## 示範

八秒循環情境示意分為四步：選取「Windows 剪貼簿歷程」（1.5 秒）、提示預設快捷鍵 Ctrl+Alt+V（1.5 秒）、顯示工具列的搜尋動作（2 秒）、呈現瀏覽器搜尋示意（3 秒）。明確標示為情境示意，說明搜尋會將選字交給設定的搜尋服務；不把示意結果當成實際搜尋回應。

提供暫停、播放與重播控制。頁籤隱藏或示範離開可視區域時停止計時；返回時繼續目前步驟。減少動態效果偏好及無 JavaScript 情境預設呈現完整靜態結果。使用文字與 CSS 示意，不新增套件、外部媒體或 AI 請求。

## 驗證

檢查中英文頁均為三個主要區段、首屏無 AI 改寫內容、第二段各只有一份改寫範例。檢查腳本語法、四步自動播放與循環、雙語暫停和重播、減少動態效果、無 JavaScript 的內容，以及桌面和手機整頁版面與 FAQ 展開狀態。

## 下載與發布整合

使用者另已同意將官網部署接在 Release 成功後，取代原先瀏覽器查詢版本、失敗時退回 rc.8 的安排。自動預覽版公開或手動 Release 附件上傳成功後，直接呼叫可重用 Pages 工作；不依賴 token 建立的 Release 再觸發事件。網站原始碼取目前 main，下載則依公開時間選取最新且 ZIP／校驗檔均完整的版本。於部署產物內填入雙語下載連結與版本，不提交來源、不觸發額外 Release。保留手動部署重試入口。流程與驗證見 `site/README.md` 及 `scripts/test-site.ps1`。
