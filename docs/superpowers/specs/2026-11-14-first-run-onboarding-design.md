# SnapBar 首次使用體驗設計

日期：2026-11-14。狀態：單一練習畫面、真實搜尋完成、首次啟動與狀態保存已實作。驗證紀錄見 `docs/p0-validation.md`；新手真人試做與多 DPI 人工驗收仍待完成。

## 目標與範圍

讓第一次開啟 SnapBar 的人，在不閱讀文件、不設定 AI 服務的情況下，完成「選字 → 按快捷鍵 → 用真正的工具列搜尋」。設計目標是約一分鐘內完成，這是待人工驗證的體驗目標，不是已量測結果。

第一版只教核心選字操作、可選的自動顯示，以及系統匣入口。AI、OCR、字典、自訂動作與登入啟動不列入首次體驗。搜尋會將範例選字交給目前搜尋服務，介面在執行前明示「搜尋會開啟瀏覽器」。不使用真實文件或剪貼簿內容作為教材。

## 現況與設計依據

- `Program.cs` 手動啟動直接顯示 `MainWindow`，背景啟動僅初始化背景服務。
- `MainWindow.Settings.cs` 預設顯示一般頁；`ApplicationSettings` 的自動偵測預設為關閉。
- 現有獨立程序 `--fixture` 可提供真實 UIA 選字來源，但文字與功能為工程測試用途，不直接當成新手畫面。
- `SelectionController.CaptureAsync` 拒絕自身程序；教學不得為方便而移除此限制。
- 現有搜尋由 `launchWeb` 成功返回表示已交給啟動器，不能證明網頁已載入或網路正常。

## 使用流程

### 一個畫面，立即練習

首次手動開啟直接呈現獨立程序的練習視窗，取代第一次直接面對完整設定。標題「選取文字，動作就在手邊。」下方立即顯示可選範例與目前快捷鍵，保留「稍後再說」、語言選擇與視窗關閉。不設獨立歡迎頁或「試一次」起始按鈕。

練習成功連線並收到可呈現的初始設定後，父程序先嘗試持久化 Presented，再通知子程序顯示；啟動失敗不消耗首次資格。略過或關閉後不在每次啟動重複打擾；之後可從「關於與支援 → 使用入門」重新開啟。舊使用者升級只增加重看入口，不自動彈出。背景登入不彈出、不消耗首次手動開啟資格。

練習畫面同時呈現三個短指示：選取下方文字、按目前快捷鍵、點工具列「搜尋」。範例為可選取的唯讀文字「SnapBar，讓文字操作更順手。」英文版本為「SnapBar keeps text actions close at hand.」。不預選文字，讓使用者親手完成選取。設定主視窗在練習呈現後隱藏，正常情況只有一個教學視窗。

工具列使用原有擷取、Probe、選取重驗證與動作執行流程。教學不製造假的工具列、不自動按鍵、不修改動作排列。若搜尋在更多選單，指示同步說明「搜尋也可能在 ⋯ 裡」。

只有來自本次練習視窗的搜尋成功交給啟動器，才在原畫面顯示「已開啟搜尋，你已學會基本操作」。此完成訊號由主程序送回練習視窗，瀏覽器開啟後不自動搶回焦點。不設「繼續」按鈕或額外完成頁，不追蹤每個教學步驟的打勾狀態。

快捷鍵未註冊時，在練習畫面提供「更換快捷鍵」，明確操作後才開啟既有設定頁，使用既有交易式儲存與衝突處理；儲存成功才更新提示。原練習工作階段保留，可從使用入門回到同一視窗，不另開第二份。若中途快捷鍵改變，練習畫面也更新。擷取失敗保留重新選字的指示；瀏覽器啟動失敗原處提示、不得算完成；不以等待時間或診斷訊息文字推斷成功。

### 原處完成與退場

搜尋成功後，原練習視窗展開「選字後自動顯示工具列」開關，初值為目前偏好，首次安裝仍預設關閉。只有使用者明確改動才由父程序透過既有保存流程更新；子程序不直接讀寫設定。保存失敗回復顯示並提示。

下方用簡短文字交代「關閉視窗後，SnapBar 會在系統匣待命。點圖示開啟設定；右鍵可暫停自動顯示或結束。」並提供「開啟設定」與「開始使用」。有系統匣時開始使用關閉教學並回背景；系統匣建立失敗時回到可見設定，不把唯一入口隱藏。

「稍後再說」略過練習後一律開啟既有設定視窗；未完成時按 Esc 或關閉練習視窗也走相同略過流程。完成後的「開始使用」及關閉行為仍回到系統匣待命。略過不降低既有 Completed 狀態，也不改動偏好。

## 狀態與保存

新增獨立 `onboarding.json`，不更動目前 schema 8 的 `settings.json`。只保存版本與狀態，不保存樣本文字、所選文字、剪貼簿、視窗身分或歷史紀錄。狀態為 `Presented`、`Skipped`、`Completed`；尚無檔案為未記錄。

啟動時，在設定初始化或語言儲存之前，記錄一般設定檔是否存在。只有「啟動時一般設定檔不存在、教學記錄不存在、沒有讀取錯誤」才自動進入首次體驗。一般設定檔已存在且沒有教學記錄，視為既有使用者。設定讀取損壞、權限不足或未支援版本時，不自動教學或覆寫檔案，保留原有錯誤處理。

背景啟動保留該次判定，第一次透過手動重複啟動或系統匣開啟時才呈現。`Presented` 保存成功後，即使程式意外結束，下次也只進設定，可由使用入門重看。教學檔案損壞或來自未支援版本時，保留檔案並抑制自動彈出；手動仍可暫時體驗，不嘗試覆寫未知格式。保存失敗提示本次進度無法保留，仍允許略過或練習，不假稱已保存。

搜尋成功時嘗試保存 `Completed`，與最終開關選擇分離；重看或中途關閉不能把已有 `Completed` 降成 `Presented`／`Skipped`。完全關閉 SnapBar 後結束練習程序，下一次不復原到練習中間步驟。

## 元件與程序邊界

- Core：`OnboardingState`、首次呈現政策與 `OnboardingStore`，負責純規則、有限大小讀取與 UTF-8 原子保存。
- App：`OnboardingCoordinator` 管理一次工作階段與清理；`OnboardingPracticeWindow` 在同一視窗提供教材、搜尋完成回饋與使用偏好。不新增 `OnboardingWindow`。
- 啟動：新增 `--onboarding-practice <pipe-name>` 分支，位於單一執行個體判定前；不讀使用者偏好、不建立系統匣或全域快捷鍵，不影響既有 `--fixture`。
- IPC：父程序建立隨機命名、`CurrentUserOnly` 的雙向 named pipe，限定單一連線。子程序回報視窗 HWND；父程序以實際子程序 PID、啟動時間及 HWND 對照原生身分，不信任訊息自行宣告的 PID。
- 通訊僅含協定版本、HWND、語言、快捷鍵、偏好布林值、請求識別、固定結果與使用者操作。保留初始設定／更新、搜尋成功／失敗、略過／結束、開啟設定／更換快捷鍵及偏好保存；刪除 toolbar-shown 與 continue。每訊息最大 4 KiB，以具界線的 JSON 行傳遞，不傳選字或搜尋 URL。連線期限 5 秒、啟動失敗在可見設定提示並提供重試；取消、斷線與應用退出都清理訂閱、pipe 及子程序資源。
- 父程序退出或 pipe 斷線時，練習程序自行關閉。正常關閉先送 close；2 秒後仍存活，只能結束此協調器持有且 PID／啟動時間相符的練習子程序，不結束其他 App／Probe。
- `SelectionController` 新增搜尋結果結構化事件，只攜帶選取識別、原始 `TargetIdentity` 與啟動成功／失敗。只在既有搜尋分支發送，不為教學新增工具列顯示事件；協調器拒絕舊工作階段與不同 HWND／PID／啟動時間。選取識別與練習工作階段分開：前者識別一次選字，後者由協調器持有的連線與訂閱識別。

## 安全、錯誤與可及性

維持密碼欄位拒絕、前景／焦點重驗證、候選身分、取消與過期政策。教學只觀察成功事件，不提供略過安全檢查的新動作入口。搜尋後瀏覽器取得前景是預期行為；完成事件對照已驗證的來源身分，不以搜尋後的前景為成功條件。

支援英文與繁中資源、Tab 順序、Enter 主動作、Esc／關閉略過、AutomationId 與可讀狀態。成功後關閉不降級為略過。首次手動啟動可以啟用練習視窗；搜尋完成、背景狀態更新不搶前景，只有使用者明確重看／重試才再次嘗試啟用。支援 100%、150%、200% DPI 與小工作區，必要時捲動，不裁掉主要按鈕。語言選擇保存沿用既有設定；失敗清楚提示，不覆寫其他偏好。

## 先驗證，再補齊

第一個可驗收版本必須串通「獨立練習視窗 → 真實選字 → 真實工具列 → 搜尋 → 原處完成」，先從手動使用入門入口啟動，不先做自動首次判定與進度保存。來源驗證、既有選字安全政策、通訊界限、取消與子程序清理從這個版本就具備。此版本僅供開發驗證，不能當成完整首次體驗對外發布。

先讓未使用過 SnapBar 的人試做，記錄到搜尋交給啟動器的時間、卡住位置及是否需要口頭協助，不記錄使用者選字內容。一分鐘是體驗目標；無新手測試時標示未驗證。確認流程後再接入教學持久化、首次啟動、雙語完整檢查與發布回歸；若需要調整，只改造成障礙的步驟，不預先添加導覽頁或完成動畫。

## 完成條件

1. 乾淨設定首次手動啟動可完成真實選字搜尋；背景啟動、舊用戶與已略過使用者不被反覆打擾。
2. 不同來源的搜尋、過期工作階段、快捷鍵衝突、瀏覽器失敗、pipe 斷線皆不能誤判完成；退出無遺留練習程序。
3. 既有快捷鍵與相容性偏好保持；雙語、鍵盤操作、多 DPI 經桌面驗收；Core、相關桌面套件與完整 Release 通過後，才具備發布資格。

本次交付來源、測試、雙語說明與新的發布說明；未推送或替換 `artifacts/p0` 套件。新手體驗及多 DPI 人工驗收的限制須與自動化通過結果分開呈現。
