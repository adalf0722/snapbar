# SnapBar 繁中與英文介面設計

日期：2026-11-08。使用者已同意完整雙語方向；本文件具體化實作範圍與驗收條件，供實作前檢閱。

## 目標與範圍

讓不懂中文的使用者從下載、啟動、設定到完成第一次選字動作，都能讀懂必要說明。首版只支援繁體中文與英文。

涵蓋工具列與更多選單、設定全部頁面、系統匣、背景通知、快捷鍵編輯、自訂動作編輯與測試、AI 設定與結果視窗、OCR、離線詞典，以及使用者可見的成功、失敗和安全提示。工具提示、螢幕閱讀器名稱及空白狀態同樣納入。保留既有 AutomationId，讓測試與輔助工具仍能穩定辨識控制項。

補上英文下載與快速入門說明、套件內英文使用說明，以及網站可找到的英文下載入口。網站本地化沿用現有靜態網站架構。既有繁中文件與已發布更新說明不覆寫。

不增加其他語言、不改動選字偵測、動作執行權限或服務供應方式。

## 語言選擇與升級

一般設定新增「語言 / Language」，選項固定顯示「跟隨系統 / System」、「繁體中文」與「English」，不使用國旗代表語言。

新安裝預設跟隨 Windows 顯示語言。繁體中文文化包含 zh-TW、zh-HK、zh-MO 與 zh-Hant；英文文化使用英文，其他未支援文化回退英文。使用 UI 顯示文化，不以數字格式文化或鍵盤輸入語言推定介面語言。

在 Core 加入可測試的語言偏好與解析政策，儲存穩定值 system、zh-Hant、en。有效舊版設定沒有語言欄位時遷移為 zh-Hant；新安裝使用 system。設定 schema 更新至 8，仍可讀取 schema 1 至 7。未知語言值安全回退 system，不因此丟棄其他有效偏好；既有未知版本、損壞檔案及不可寫檔案的保護行為保留。

顯式選擇優先於系統語言並跨啟動保存。切換語言不變更快捷鍵、相容性、登入啟動、自動偵測、排除清單、搜尋網址或既有動作。

## 文字資源與責任邊界

Core 負責語言設定、遷移與解析，不依賴 WPF。App 負責以穩定資源鍵取得繁中及英文文字、格式化帶參數的訊息，以及更新可見介面。Windows 與 Probe 保留機器可讀代碼；App 將其映射為目前語言的提示，不以翻譯文字改動通訊協定或安全判斷。

介面資源採成對的 .resx 檔案與集中式資源存取入口，避免散落語言條件或以中文整句充當識別鍵。內建動作依既有穩定識別碼取得顯示名稱，不將翻譯後名稱回寫成使用者設定。英文作為缺少資源的回退；驗證必須檢出缺鍵與格式參數不一致，不能將回退視為翻譯完成。

僅翻譯產品擁有的文字。使用者自訂名稱、腳本、AI 提示詞、AI 生成內容、詞典內容、OCR 結果、選取文字及外部服務原始回應保持原文。內建可編輯範例只在建立新項目時提供目前語言版本，不遷移或覆寫已保存內容。

## 切換與工作狀態

成功保存後立即更新設定頁、系統匣與其後顯示的視窗，不要求重啟。App 以單一語言變更通知更新產品文字；不得以重新啟動 App、重新註冊熱鍵或重建選字控制器達成切換。

已開啟視窗保留目前頁籤、選項、捲動位置、編輯草稿及操作結果。帶有草稿的控制項更新標籤與說明，不重建其資料。已有非同步工作完成時以當時介面語言呈現產品狀態，仍沿用既有取消與選取驗證。

如果語言偏好無法保存，保留原偏好和原介面語言，以目前語言說明保存失敗。跟隨系統時於啟動及重新開啟設定時解析系統顯示語言；不新增常駐輪詢。

## 版面與英文文案

採常見英文操作詞，如 Copy、Cut、Paste、Search、Settings、Quit SnapBar。錯誤提示說明使用者下一步能做什麼，不直接翻譯內部技術術語。

檢查英文較長字串的換行、按鈕寬度、選單與工具提示。沿用現有視覺樣式，必要時調整彈性寬度與換行；不藉本案重做整體介面。語言入口在兩種介面下皆可辨識。

介面語言不連動 OCR 語言優先順序、AI 回答語言或任何既有翻譯目標設定。英文使用者的首次使用文件要清楚交代 OCR 模型、詞典匯入、AI 憑證與 Node.js 等對應功能的必要條件，依目前產品實際支援內容撰寫。

## 驗證與交付

Core console runner 覆蓋新安裝、舊版遷移、手動偏好優先、系統繁中變體、其他語言回退、未知語言值、重載及保存失敗；確認其他偏好完整保留。資源驗證檢查雙語鍵集合與格式參數。

桌面測試覆蓋一般設定的雙語入口與即時切換、系統匣與通知、主工具列、更多選單、錯誤提示、AI／動作編輯草稿保留，以及重新啟動後的語言偏好。沿用固定 AutomationId，避免既有測試依賴繁中顯示文字。測試不更動使用者的 Windows 顯示語言，文化情境使用可注入的解析輸入。

執行 scripts/check.ps1 及相關桌面套件，必要時執行完整 Release；桌面測試前確認 SnapBar 已正常結束，避免干擾使用者的前景與剪貼簿。以繁中與英文畫面截圖檢查一般設定、工具列及至少一個編輯／結果視窗，記錄實際執行的 DPI；未測的跨應用及 DPI 情境明確列出，不宣稱通過。

在 docs/p0-validation.md 記錄驗證與截圖位置。新增獨立繁中 release-notes/2026-11-08-interface-language.json，包含使用者效益、切換入口及必要條件，不修改已發布的說明。

完成條件是英文使用者可依英文說明下載並啟動、設定快捷鍵、完成一次選字動作、理解關閉後仍在背景執行及如何完整結束，且既有繁中使用者的設定與工作內容保持完整。此任務不包含推送或公開發布；若要產生套件，仍遵守現有桌面證據與打包門檻。
