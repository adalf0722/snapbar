# 編輯頁與動作清單收尾

使用者已同意 2026-10-31 的畫面建議；本輪實作前兩項，保留目前視覺風格與設定頁。

## 編輯頁

將固定 184 DIP 的內容編輯區改為預設 120 DIP、可垂直調整的區域，最小 96、最大 480 DIP。把手提供滑鼠拖曳、上下鍵調整與 Home 還原。縮減欄位間的多餘留白，維持字級與 36 DIP 按鈕。一般 1080 × 850 視窗的基本欄位、結果說明與收合的進階入口應完整可見；最小視窗仍可捲動，儲存列固定。展開進階設定維持既有欄位捲入視野行為。調整編輯區尺寸不更動腳本、草稿或測試結果。

## 動作管理

分頁已提供群組名稱與數量，移除清單內的重複標題；內建動作只顯示名稱，自訂動作保留執行類型。動作列每列加入可見的六點拖曳把手，名稱也能繼續拖曳；超過系統拖曳門檻才開始操作。保留上下移按鈕、顯示位置選擇、六個釘選上限與保存流程。不增加新的設定欄位。

## 驗證

以暫存設定執行既有 UI appearance 與 action layout runner，檢查一般與最小視窗、調整高度上下界、編輯內容保留、分頁數量與排序保存。檢視實際 WPF 截圖，執行建置與相關測試後發佈。第三項的完整日常使用流程不擴充為本輪新功能。
