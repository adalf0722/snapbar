# SnapBar

繁體中文 · [English](README.en.md)

**選取文字，動作就在手邊。**

SnapBar 是 Windows 的選字工具列。在正在使用的 App 裡選取一段文字，按 **Ctrl + Alt + V**，就能在文字旁複製或搜尋。

[前往 Releases 下載 Windows x64 預覽版](https://github.com/adalf0722/snapbar/releases)

![反白選字後，SnapBar 工具列出現在文字下方，顯示複製、剪下、貼上、搜尋與更多動作。](site/assets/selection-detail.png)

## 第一次使用

1. 在 Releases 選擇預覽版本，展開 **Assets** 並下載檔名符合 `SnapBar-*-win-x64.zip` 的套件。
2. 完整解壓縮 ZIP，再開啟 `SnapBar.App.exe`。這是免安裝的未簽章預覽版，套件已包含 .NET 執行環境。
3. 在瀏覽器選取一段網頁文字，按 **Ctrl + Alt + V**，再點工具列的「搜尋」。預設瀏覽器會開啟這段文字的搜尋結果。

想在拖曳或雙擊選字後直接看到工具列？到 SnapBar 設定的「一般」開啟「自動顯示動作列」。首次使用預設以快捷鍵叫出。

在「一般 → 語言 / Language」可選擇跟隨系統、繁體中文或 English。新安裝跟隨 Windows 顯示語言，未支援語言使用英文；既有使用者升級後保留繁中。設定與系統匣立即更新，已開啟的編輯／結果視窗重新開啟後採新語言，不會改動既有內容與偏好。

## 常用動作與 AI 改寫

- **複製、剪下、貼上與搜尋。** 網頁文章等唯讀文字也能複製或搜尋。選取完整的 HTTP／HTTPS 網址或檔案路徑後，可在「⋯」選「開啟連結」或「檔案位置」。
- **把常用動作放在前面。** 在設定的「動作列」調整順序、釘選最多 9 個動作，並切換純圖示或圖示與文字。畫面寬度不足時，尾端動作會收進「⋯」。也可自訂搜尋網址，或新增網址、PowerShell 和 JavaScript 動作。JavaScript 需要 Node.js，腳本會以目前的 Windows 使用者權限執行。
- **先預覽，再決定是否替換原文。** 在設定的「AI 服務」填入服務端點、模型和服務所需的 API 金鑰。接著選字，從「⋯」開啟「AI 改寫」，試著送出「把這段話改短一點」。你可以比較原文與結果、接著修訂或複製結果。來源仍可編輯且選取通過重新驗證時，可以直接替換原文。
- **在選字旁離線查詞。** 到「動作列 → 更多 → 字典 → 管理詞典」匯入 StarDict 2.4.2 的 `.ifo`，同一資料夾需有 `.idx` 和 `.dict` 或 `.dict.dz`。支援 UTF-8 純文字釋義與音標，需自行準備詞典。可匯入多本詞典，直接查看名稱與可查詢的詞條數，並各自啟用、停用或移除；同名匯入會先詢問是否更新。選取英文單字或短語後，從「⋯」點「字典」，即可一次搜尋已啟用的詞典，依來源查看及複製釋義。第一次查詞也可從小窗直接進入匯入畫面。查詞在本機執行，既有單本詞典會自動沿用。
- **擷取畫面上無法選取的字。** 在系統匣右鍵選「框選 OCR」，或在「一般 → 選字快捷鍵」綁定同名動作。在單一螢幕上拖曳框選，按 Esc 可取消。繁中與英文在本機辨識，預設繁中優先，可在「一般 → OCR 語言優先順序」切換。結果可校正、反白、複製、搜尋。OCR 引擎需要 [Microsoft Visual C++ x64 執行階段](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。

## 工具列沒出現？

1. 在系統匣點 SnapBar 圖示回到設定。到「關於與支援 → 診斷與測試 → 開啟測試視窗」，選取測試文字，再按快捷鍵。
2. 如果測試視窗也叫不出工具列，到「一般 → 叫出動作列」確認目前的快捷鍵。若按鍵被其他程式占用，點「更換」設定另一組。
3. 如果只有特定 App 讀不到文字，到「相容性」確認「選字相容模式」已開啟。使用 Sublime Text 時，再開啟「Sublime 支援」。首次啟用會加入 SnapBar 使用的快捷鍵綁定。

工具列會依來源 App 提供的選取與編輯資訊顯示可用動作，並略過密碼欄位。若選取或焦點已變更，請重新選字再執行寫回動作。也可把 App 加入「排除 App」，讓該 App 只在按快捷鍵時叫出工具列。

## 系統匣與更新

關閉設定視窗後，SnapBar 會留在系統匣。點圖示可回到設定，按右鍵可暫停或啟用自動偵測。更新時，先從系統匣選「結束 SnapBar」，再完整解壓縮並開啟新版。

## 資料處理

SnapBar 優先使用 Windows UI Automation 讀取選取文字。相容模式可能暫借剪貼簿並嘗試還原，暫存內容也可能出現在 Windows 剪貼簿歷程。

一般設定檔保存快捷鍵、動作列與相容性等偏好。執行搜尋、網址或使用選取文字的腳本動作時，所選文字會交給對應的瀏覽器或腳本。只有執行 AI 指令時，SnapBar 才會把文字送往你設定的 AI 服務。AI 金鑰由 Windows 加密保存，改寫結果保留於當次面板。

框選 OCR 的影像在本機記憶體處理。結果視窗只在你執行搜尋時，把所選的結果文字交給搜尋引擎。
