# SnapBar Windows P0

這是選字工具的早期版本，已加入系統匣、設定保存、排除 App、搜尋與開啟連結。更新前先完整結束舊版；請完整解壓縮，再開啟 `SnapBar.App.exe`。Windows x64 執行環境已包含在套件中。

1. 按「開啟測試視窗」。
2. 在測試視窗選取文字，按 Ctrl+Alt+V。
3. 選取附近會出現複製／剪下／貼上／搜尋動作列。整段有效 HTTP／HTTPS 網址另提供「開啟連結」。
4. 需要自動觸發時，回設定視窗按「啟用自動偵測」；首次預設關閉，之後記住偏好。
5. 關閉設定視窗後留在系統匣。左鍵圖示可返回，右鍵可暫停／恢復或結束；暫停不影響手動快捷鍵。
6. 完整結束請選「結束 SnapBar」；獨立測試視窗需另行關閉。重複啟動會叫回原設定視窗。

設定存於 `%LOCALAPPDATA%/SnapBar/settings.json`，保存自動偵測偏好、排除清單與搜尋網址範本，不保存選取原文或剪貼簿。v1／v2 設定保留偏好升級至 v3；損壞／較新版本的檔案保留不覆寫。Sublime 相容模式仍每次自行啟用。

搜尋預設交由 Google。展開「搜尋設定」，可保存如 `https://www.google.com/search?q={query}` 的自訂範本，或恢復預設。僅接受 HTTP／HTTPS，且一個 `{query}` 必須在參數值中；文字會自動編碼。範本上限 2,048 字元，產生網址上限 8,192 字元；超長會提示。只有點擊動作才開啟瀏覽器，選取本身不會送出。唯讀文字也可搜尋；「開啟連結」只接受整段完整網址，不猜測協定，不接受帳密或原始空白。兩者執行前皆重新驗證選取。

展開「排除 App」後，按「加入 App…」選擇實際程式的 `.exe`，不會執行檔案。該 App 的自動讀取與浮窗會停用，手動 Ctrl+Alt+V 仍可使用。新增／移除立即保存，重啟保留；以完整路徑識別，不同安裝位置分開處理。

請先在可丟棄的測試文字中驗證 Cut／Paste。預設讀取使用 UI Automation。唯讀、未知狀態、非焦點 provider、多段選取及密碼欄位受限制。

本版改善 UIA 首次／間歇沒有選字介面的情況：有限重新查詢、等待 provider 就緒，並支援較深的控制項祖先鏈。一般查詢成功時沒有固定額外等待；空選取與密碼不重試，ChatGPT 不注入剪貼簿快捷鍵。已用延遲及深層 fixture 驗證，ChatGPT 桌面 App 的冷啟動首次選字仍需實際回測。選到 ChatGPT 回覆而顯示「唯讀」是正常狀態，可複製、搜尋，整段有效網址可開啟連結。

## Sublime Text

先關閉舊版 SnapBar，再執行這份新版。勾選「Sublime 剪貼簿相容模式（可編輯時提供剪下／貼上）」，在 Sublime 選取單段文字後按 Ctrl+Alt+V。自動顯示另需按「啟用自動偵測」。每次啟動需重新勾選。

此模式不安裝程式外掛；啟用時會備份並修改 `%APPDATA%/Sublime Text/Packages/User/Default (Windows).sublime-keymap`。舊版兩條綁定可自動升級；新版有 Ctrl+Alt+Shift+F12／F11／F10／F9 共八條綁定，依序負責一般讀取、可編輯讀取、剪下、貼上及各自的預設 noop。寫入要求單段非空選取、可編輯且不是面板／覆蓋介面；動作前重新驗證。若設定衝突就不啟用；攜帶版暫不支援。

讀取會暫借剪貼簿並嘗試完整還原。支援文字、常見圖片、檔案清單及可備份的註冊格式；任一格式無法備份或總量超過 64 MiB，整次探測會停止。剪貼簿歷程仍可能記錄暫存內容；新輸入、並行複製、極慢目標或強制結束程序可能使還原失效。取消勾選可停止使用；移除 Sublime 設定中 SnapBar 註解下全部八條綁定可撤回設定，也可從啟用前產生的 `.snapbar-*.bak` 備份恢復（先保留之後自行新增的設定）。

已在 Sublime Build 4180 實測手動、雙擊及拖曳選字；控制器整合驗證與畫面核對確認複製／剪下／貼上結果，以及唯讀、多游標、搜尋面板和動作前改變目標時的防護。自動化尚未直接點擊不搶焦點的浮窗按鈕，仍需人工補驗。指令送出後，狀態會要求確認原 App 結果。相同文字被背景程式移到另一範圍仍可能無法識別；請先用可丟棄文字測試。
