# SnapBar Windows P0

繁體中文 · [English](README.en.md)

「一般 → 語言 / Language」可切換跟隨系統、繁體中文或 English。新安裝跟隨 Windows 顯示語言，未支援語言使用英文；既有使用者保留繁中。設定與系統匣立即更新，已開啟的編輯／結果視窗重新開啟後採新語言。

這是 Windows 選字工具，提供系統匣、設定保存、排除 App、搜尋、開啟連結、檔案位置、自訂動作與 AI 改寫。更新前先完整結束舊版；請完整解壓縮，再開啟 `SnapBar.App.exe`。Windows x64 執行環境已包含在套件中。

1. 到「關於與支援 → 診斷與測試」按「開啟測試視窗」。
2. 在測試視窗選取文字，按 Ctrl+Alt+V。
3. 選取附近會出現複製／剪下／貼上／搜尋動作列。「開啟連結」與「檔案位置」預設在「⋯」更多選單，也可自行釘選。
4. 需要自動觸發時，到「一般」開啟「自動顯示動作列」；首次預設關閉，之後記住偏好。
5. 關閉設定視窗後留在系統匣。左鍵圖示可返回，右鍵可暫停／恢復或結束；暫停不影響手動快捷鍵。
6. 完整結束請選「結束 SnapBar」；獨立測試視窗需另行關閉。重複啟動會叫回原設定視窗。

在系統匣右鍵選「框選 OCR」，可拖曳擷取繁中與英文，按 Esc 取消。結果可以校正，再複製或搜尋。模型與引擎隨套件提供，OCR 另需 [Microsoft Visual C++ x64 執行階段](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。

設定存於 `%LOCALAPPDATA%/SnapBar/settings.json`，保存語言、自動偵測偏好、排除清單、搜尋與動作設定，不保存選取原文或剪貼簿。v1–v7 設定保留偏好升級至 v8；損壞／較新版本的檔案保留不覆寫。Sublime 支援需要首次明確設定，之後保留選擇。

「管理動作」可設定單排動作列的外觀、最多 9 個常用動作、排序、更多與隱藏。預設釘選四個，新釘選接到最後。「動作列」分頁顯示釘選數量和上限，預覽顯示完整釘選順序，包含條件動作。純圖示和圖示與文字共用同一份排列。實際浮窗依選字情境收起不適用動作，寬度不足時把尾端收進更多。展開更多時不搶來源焦點；點入搜尋欄後有原生游標，可正常輸入、選字、編輯及貼上。上下／Enter／Esc 操作結果，執行前返回原來源重驗，切到別的 App 就取消。自訂動作可選網址、PowerShell、JavaScript、Python；新增與匯入先進入更多。網址用 `***` 代入編碼後選取；腳本用 `POPCLIP_TEXT` 環境變數取得原文，不拼入指令參數。JavaScript 需要 Node.js，Python 需要自行安裝 Python 3；可指定執行環境完整 `.exe` 路徑。Python 預設尋找 PATH 中的 `python.exe`，進階設定也可指定虛擬環境的 `Scripts/python.exe`；額外套件須自行安裝於該環境。

腳本逾時 1–300 秒（預設 10），stdout／stderr 各有 256 Ki 字元上限。測試按鈕會用範例文字實際執行，保存／匯入不執行。每次請求的子程序在完成、取消或逾時時一併清理。結果可複製、顯示、基本 Markdown 排版或在原來源仍有效且可編輯時替換。替換會把結果寫入剪貼簿再送出貼上；空結果不刪除原文。自訂動作的「⋯」提供複製／刪除／匯出，匯入 `.snapbaraction` 先預覽完整內容。設定最多 32 個自訂動作且整份檔案上限 64 KiB。

設為更多選單的項目固定留在「⋯」內；不適用時顯示灰色及原因，不會消失或自動移到動作列。「檔案位置」需要完整路徑才啟用；鍵盤導覽略過不可執行項目。

搜尋預設交由 Google。展開「搜尋設定」，可保存如 `https://www.google.com/search?q={query}` 的自訂範本，或恢復預設。僅接受 HTTP／HTTPS，且一個 `{query}` 必須在參數值中；文字會自動編碼。範本上限 2,048 字元，產生網址上限 8,192 字元；超長會提示。只有點擊動作才開啟瀏覽器，選取本身不會送出。唯讀文字也可搜尋；「開啟連結」只接受整段完整網址，不猜測協定，不接受帳密或原始空白。兩者執行前皆重新驗證選取。

「檔案位置」支援完整磁碟路徑、UNC、`%USERPROFILE%`、`~`、中文、空白及外層雙引號。資料夾直接開啟本身，例如 `D:\codex`；檔案則開啟父資料夾並選取，不執行檔案。唯讀文字也可用；工具列出現時不查詢檔案或網路。獨立 helper 每次請求最多 1.5 秒，查詢後再驗證選取，失效則取消；不存在、無權限或逾時會提示。拒絕相對路徑、裝置路徑、其他環境變數、萬用字元及資料流；不把路徑拼入命令列或寫入診斷。網路分享仍待人工驗收，Shell 已接收的開啟動作無法撤回。

展開「排除 App」後，按「加入 App…」選擇實際程式的 `.exe`，不會執行檔案。該 App 的自動讀取與浮窗會停用，手動 Ctrl+Alt+V 仍可使用。新增／移除立即保存，重啟保留；以完整路徑識別，不同安裝位置分開處理。

請先在可丟棄的測試文字中驗證 Cut／Paste。預設讀取使用 UI Automation。唯讀、未知狀態、非焦點 provider、多段選取及密碼欄位受限制。

本版改善 UIA 首次／間歇沒有選字介面的情況：有限重新查詢、等待 provider 就緒，並支援較深的控制項祖先鏈。一般查詢成功時沒有固定額外等待；空選取與密碼不重試，ChatGPT 不注入剪貼簿快捷鍵。已用延遲及深層 fixture 驗證，ChatGPT 桌面 App 的冷啟動首次選字仍需實際回測。選到 ChatGPT 回覆而顯示「唯讀」是正常狀態，可複製、搜尋，整段有效網址可開啟連結。

## Sublime Text

本次修復「來源暫時未提供格式」直接停止的問題：釋放鎖後等待 40／80 ms，最多額外重試兩次並重建完整備份。若輸入或剪貼簿已變更，停止並保留當前內容；永久不可用格式仍安全拒絕，顯示已保留原內容，不再只要求稍後再試。不完整／已使用的備份不能還原或清空剪貼簿。本輪重跑 250 項相關檢查，包含真實 Sublime 在延遲備份失敗後自動恢復、還原及複製；詳見 `CLIPBOARD-RECOVERY.md`，其餘功能基線記錄於下方與 `VALIDATION.md`。

先關閉舊版 SnapBar，再執行這份新版。在相容性設定啟用「Sublime 支援」，在 Sublime 選取單段文字後按 Ctrl+Alt+V。自動顯示另需啟用自動偵測。首次設定會加入受保護的快捷鍵綁定，之後保留選擇。

此模式不安裝程式外掛；啟用時會備份並修改 `%APPDATA%/Sublime Text/Packages/User/Default (Windows).sublime-keymap`。舊版兩條綁定可自動升級；新版有 Ctrl+Alt+Shift+F12／F11／F10／F9 共八條綁定，依序負責一般讀取、可編輯讀取、剪下、貼上及各自的預設 noop。寫入要求單段非空選取、可編輯且不是面板／覆蓋介面；動作前重新驗證。若設定衝突就不啟用；攜帶版暫不支援。

讀取會暫借剪貼簿並嘗試完整還原。支援文字、常見圖片、檔案清單及可備份的註冊格式；任一格式無法備份或總量超過 64 MiB，整次探測會停止。剪貼簿歷程仍可能記錄暫存內容；新輸入、並行複製、極慢目標或強制結束程序可能使還原失效。取消勾選可停止使用；移除 Sublime 設定中 SnapBar 註解下全部八條綁定可撤回設定，也可從啟用前產生的 `.snapbar-*.bak` 備份恢復（先保留之後自行新增的設定）。

已在 Sublime Build 4180 實測手動、雙擊及拖曳選字；控制器整合驗證與畫面核對確認複製／剪下／貼上結果，以及唯讀、多游標、搜尋面板和動作前改變目標時的防護。自動化尚未直接點擊不搶焦點的浮窗按鈕，仍需人工補驗。指令送出後，狀態會要求確認原 App 結果。相同文字被背景程式移到另一範圍仍可能無法識別；請先用可丟棄文字測試。

## AI 改寫

先在主設定按「設定 AI 服務」，選擇 OpenAI 或自訂相容服務，填入完整 API 網址、模型 ID 與 API Key。本機相容服務可不填金鑰。選取文字後從「⋯」按「AI 改寫」；也可在管理動作中釘選 AI。

面板開啟直接顯示原文，結果以分頁切換。左側同一個輸入框可搜尋所有已存指令，也可直接輸入要求；Enter 執行輸入內容，方向鍵或滑鼠選擇指令後 Enter 執行該項，Shift+Enter 換行。完成後可接著要求「再短一點」，或從原文重做。釘選、最近使用、自訂指令及每個服務的模型會保存；版本歷史只留在本次面板。

「替換原文」會重新驗證原選取，複製結果並送出貼上指令；請返回原 App 確認。唯讀與來源失效時保留「複製結果」。只有明確執行指令才向所選服務傳送文字，結果不會執行程式或載入遠端資源。AI 一般設定存於 `ai.json`，金鑰以 Windows 使用者範圍的 DPAPI 分開加密保存；不隨套件分享。服務與模型相容性仍需使用自己的設定確認。

「一般」設定提供快捷鍵更換、恢復預設及「登入 Windows 後自動啟動」。啟用後登入時在系統匣待命；若被 Windows 停用，依提示到 Windows 設定恢復。請使用完整解壓縮的套件，搬動資料夾後重新啟用。開發用 bin 目錄的版本可能依賴開發環境，無法獨立啟動時不會新增登入啟動項目。目前沒有自動更新。更多面板可點入原生文字搜尋欄，顯示游標並正常編輯；不同 Windows 輸入法的候選選字細節仍待人工補驗。套件尚未簽章。最新功能及測試證據見 `VALIDATION.md`；下段為原有功能基線。
