A PopClip alternative for Windows

PopClip is available only for macOS. If you want a floating toolbar beside selected text on Windows, try SnapBar, an open-source app inspired by PopClip.

Search or copy selected text

  1. Highlight text in a browser or editor, such as an error code.
  2. Press Ctrl + Alt + V to open the SnapBar toolbar.
  3. Choose Search to look up the exact text in your browser, or Copy to put it on the clipboard.

To open the toolbar when you select text, turn on automatic display in SnapBar’s General settings. Selection support varies by app.

Try SnapBar on Windows x64

Download the preview ZIP, extract all files, and run SnapBar.App.exe. The package includes .NET. Follow the practice guide on first launch to try a search.
