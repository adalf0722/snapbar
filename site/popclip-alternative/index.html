PopClip 有 Windows 版嗎？

PopClip 官方只提供 macOS 版。如果你習慣在選字後從旁邊的浮動工具列執行動作，可以在 Windows 試用受 PopClip 啟發的開源工具 SnapBar。

選字後直接搜尋或複製

  1. 在瀏覽器或文字編輯器反白一段文字，例如錯誤碼。
  2. 按 Ctrl + Alt + V 叫出 SnapBar 工具列。
  3. 點「搜尋」，瀏覽器就會查詢選取的文字。也可以點「複製」把文字放進剪貼簿。

想讓工具列選字後自動出現，可以在 SnapBar 的「一般」設定啟用自動顯示。選取支援依 App 而異。

在 Windows x64 試用 SnapBar

下載預覽版 ZIP，完整解壓縮後執行 SnapBar.App.exe。套件內含 .NET，首次開啟可跟著內建練習完成一次搜尋。
